Here is the corrected and organized procedure for installing the **Burp Suite CA certificate as a System (Root) Certificate** on an **Android Emulator**.

---

# Install Burp Suite CA Certificate as a System Certificate on Android Emulator

## Step 1: Create a Working Directory

```bash
mkdir certs
cd certs
```

---

## Step 2: Download the Burp CA Certificate

1. Start **Burp Suite**.
2. Configure the emulator to use Burp as its proxy.
3. Open the browser inside the emulator.
4. Visit:

```
http://burp
```

or

```
http://burp/cert
```

5. Download the certificate (`cacert.der`).

---

## Step 3: Move the Certificate

If the certificate was downloaded on Windows:

```bash
mv /mnt/c/Users/veena/Downloads/cacert.der .
```

Check that it exists:

```bash
ls
```

---

## Step 4: Convert DER to PEM

```bash
openssl x509 -inform DER \
-in cacert.der \
-out cacert.pem
```

---

## Step 5: Generate Android Certificate Hash

Android requires certificates to be named with the old subject hash.

```bash
openssl x509 \
-in cacert.pem \
-subject_hash_old \
-noout
```

Example output:

```
9a5ba575
```

Rename the certificate:

```bash
cp cacert.pem 9a5ba575.0
```

Replace `9a5ba575` with the hash shown on your system.

Verify:

```bash
ls
```

---

# Step 6: Start the Emulator in Writable Mode

Open **Command Prompt** on Windows.

Go to the emulator directory:

```cmd
cd C:\Users\veena\AppData\Local\Android\Sdk\emulator
```

List available AVDs:

```cmd
emulator.exe -list-avds
```

Example:

```
Pixel_6a
```

Start the emulator with a writable system partition:

```cmd
emulator.exe -avd Pixel_6a -writable-system
```

---

# Step 7: Restart ADB as Root

```bash
adb root
adb remount
```

If `adb remount` succeeds, the `/system` partition becomes writable.

---

# Step 8: Copy the Certificate to the Emulator

```bash
adb push 9a5ba575.0 /sdcard/
```

---

# Step 9: Copy the Certificate to the System CA Store

Open a shell:

```bash
adb shell
```

Become root:

```bash
su
```

Copy the certificate:

```bash
cp /sdcard/9a5ba575.0 /system/etc/security/cacerts/
```

Or use a single command:

```bash
adb shell su -c "cp /sdcard/9a5ba575.0 /system/etc/security/cacerts/"
```

---

# Step 10: Set Correct Permissions

```bash
adb shell su -c "chmod 644 /system/etc/security/cacerts/9a5ba575.0"
```

Set ownership (if needed):

```bash
adb shell su -c "chown root:root /system/etc/security/cacerts/9a5ba575.0"
```

---

# Step 11: Reboot the Emulator

```bash
adb reboot
```

---

# Verify the Certificate

After reboot:

```
Settings
→ Security
→ Trusted Credentials
→ System
```

You should see the **PortSwigger Burp Suite CA** certificate.

---

# Complete Command Summary

```bash
mkdir certs
cd certs

mv /mnt/c/Users/veena/Downloads/cacert.der .

openssl x509 -inform DER -in cacert.der -out cacert.pem

openssl x509 -in cacert.pem -subject_hash_old -noout

cp cacert.pem <hash>.0

adb root
adb remount

adb push <hash>.0 /sdcard/

adb shell su -c "cp /sdcard/<hash>.0 /system/etc/security/cacerts/"

adb shell su -c "chmod 644 /system/etc/security/cacerts/<hash>.0"

adb shell su -c "chown root:root /system/etc/security/cacerts/<hash>.0"

adb reboot
```

Replace `<hash>` with the value returned by:

```bash
openssl x509 -in cacert.pem -subject_hash_old -noout
```

For example, if the hash is `9a5ba575`, the certificate filename must be `9a5ba575.0`. This exact naming is required for Android to recognize the certificate as a trusted system CA.
