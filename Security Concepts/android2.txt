By default, the adb.exe file for Android Studio on Windows is located at:
C:\Users\<Your-Username>\AppData\Local\Android\Sdk\platform-tools\

You can easily copy and paste %LOCALAPPDATA%\Android\Sdk\platform-tools into your Windows File Explorer address bar to jump straight to the folder.

Step-by-Step Guide to Root an AVD with rootAVD

1. Set up Android Studio and AVD:
	- Install Android Studio.
	- Open Device Manager (Tools → Device Manager) and create/start an AVD (preferably x86_64 with Google Play Store APIs).
	- Ensure Android SDK Platform-Tools (for adb) is installed via SDK Manager.

2. Download rootAVD:

git clone https://gitlab.com/newbit/rootAVD.git
cd rootAVD/

3. List available AVD images:

./rootAVD.sh ListAllAVDs   # Linux/macOS
# or
rootAVD.bat ListAllAVDs    # Windows

This shows the exact path to your AVD's ramdisk.img (or ramdisk-qemu.img for some images).

4. Root the running AVD:

 - Keep the emulator running.
 - Run the command for your specific image (example for API 33/34 x86_64):
 	rootAVD.bat system-images/android-33/google_apis_playstore/x86_64/ramdisk.img
The script will:
- Download/install a Magisk version (you can choose Stable/Canary/Alpha).
- Patch the ramdisk.
- Optionally install apps from the Apps/ folder.
- Create backups of original files.

5. Restart the emulator:	
 - Close the emulator completely.
 - In Android Studio Device Manager, select Cold Boot (important for the patches to take effect).

6. Verify root:
 - Open Magisk app in the emulator (it should be pre-installed).
 - Run adb shell and type su — you should get root shell (# prompt).
