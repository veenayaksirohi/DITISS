Computer Network Basics

Computer Network

A computer network is a set of devices connected through links.

Simply: Computers connected together.

Network

A network is a set of devices that are connected with a physical media or link.

Two or more nodes are connected through physical or wireless links, and two or more networks are connected by nodes like routers.

  • Nodes → Connected via physical links
  • Networks → Connected via nodes

Node

Node = any device connected to a network that can communicate data


A node in networking is any device that can send, receive, or forward data on a network. Computer 💻 Router 📡

Basic Terms

Client

A client is a program that initiates communication by sending requests.

A client is a software or device that requests services or resources.

Runs on: User device (PC, Phone)

Server

A server can handle multiple clients simultaneously depending on the service.

Examples:

  • File Server
  • Database Server
  • Media Server
  • Print Server
  • Web Server

Runs on: Dedicated machine or cloud.

Client → Request

Server → Response

Client request Server responds

Real Life Analogy

Restaurant:

  • Client → Place order

Host

Host is a computer connected to other computers that provides data or services over the network.

Peer

A peer is a node that provides the same functionality as another.

Correction: Client and Server are NOT peers because their functions are different.

Hub

A hub is a basic networking device that connects multiple computers in a LAN and broadcasts data to all connected devices.

Operates at: Physical Layer (Layer 1)

Types of Hub

  • Passive Hub → Only connects devices → Does NOT amplify signal
  • Active Hub → Amplifies and regenerates signal before forwarding
  • Intelligent Hub → Monitors traffic → Used for network management

Ethernet Hub

  • Hub specially designed for Ethernet networks
  • Uses Ethernet cables (RJ-45)
  • Works at 10 / 100 Mbps
  • Operates at Half-Duplex

Correction: Hubs are now mostly obsolete and replaced by switches.

Repeater

A repeater is a device that regenerates and strengthens signals to extend network distance.

Purpose: Increase network range

Types of Repeaters

  • Wired Repeater
  • Wireless Repeater
  • Digital Repeater
  • Analog Repeater
  • Optical Repeater

Bridge

A bridge connects two LANs to form an extended LAN and forwards frames based on MAC addresses. It helps reduce network traffic by sending data only to the required segment A bridge is basically an older version of a switch. Modern networks mostly use switches instead of bridges

Feature Bridge Switch
Role Connects a few LAN segments Modern replacement of bridge

Speed Slower Faster

Operates at: Data Link Layer (Layer 2)

Types of Bridge

  • Transparent Bridge
  • Source Routing Bridge

Switch

A switch forwards data to the correct destination using MAC address.

  • Operates at Layer 2 (Data Link Layer)
  • Operates in Full Duplex

Types of Switch

  • Unmanaged Switch → Plug and play
  • Managed Switch → VLAN support → Monitoring features
  • Layer 3 Switch → Can perform routing

Modem

Modem (Modulator + Demodulator) is a device that converts digital signals to analog and analog signals to digital.

  • Digital → Analog → Modulator
  • Analog → Digital → Demodulator

Purpose: Connect computer to internet using telephone lines.

Gateway

Gateway is a device that connects different networks using different protocols.

Functions

  • Protocol Conversion
  • Data Translation
  • Connecting LAN to WAN

Default Gateway = First usable IP address of network.

Correction: Common default gateway addresses:

  • 192.168.0.1
  • 192.168.1.1

Router

A router is a device that forwards data packets from one network to another, ensuring it reaches the correct destination. A router forwards packets based on IP address.

Router Key Functionalities

  1. Data packet forwarding
  2. Path selection (routing)
  3. Network Address Translation (NAT)
  4. IP address assignment (DHCP)
  5. Traffic management
  6. Firewall / security control
  7. Wireless connectivity (Wi-Fi)
  8. Inter-network communication

Operates at: Network Layer (Layer 3)

Routing Table

Stores routing information used to forward packets.

Types of Routing

  • Static Routing → Routing information entered manually → Used in small networks
  • Dynamic Routing → Routing information updated automatically → Uses routing protocols

Routing Protocols

NIC (Network Interface Card)

NIC (Network Interface Card)

A Network Interface Card (NIC) is a hardware component that connects a computer to a network. It acts as a bridge between the device and the network by converting data into signals for transmission.

It works mainly at the Data Link Layer (Layer 2) of the OSI model and also interacts with the Physical Layer (Layer 1).

A Network Interface Card (NIC) is a hardware component that enables a computer or device to connect to a network (LAN or Internet). It acts as the communication bridge between the device and the network by converting data into signals (and vice versa) for transmission. Modern NICs are usually built into the motherboard, but they can also exist as PCIe expansion cards or USB adapters. They support both wired (Ethernet) and wireless (Wi-Fi) connections. A NIC primarily works at the Data Link Layer (Layer 2) of the OSI model, using MAC addresses to identify devices and organizing data into frames. It also interacts with the Physical Layer (Layer 1) by sending and receiving electrical or radio signals.

Measured in:

Line Encoding is the process of converting binary data into time-based signals.

Binary Data → Digital Signals

Bits are represented using voltage levels.

Types of Line Encoding

  • Manchester Encoding
  • Differential Manchester Encoding

Manchester Encoding

Representation:

  • 0 → Low to High transition
  • 1 → High to Low transition

Differential Manchester Encoding

Representation:

  • 0 → Transition at beginning
  • 1 → No transition at beginning

  • Intermodulation Noise

Attenuation

Attenuation: Loss of signal strength while transmitting through cables.

Cause:

  • Resistance in cable
  • Distance increase

Signal gets weaker as distance increases.

Distortion

Distortion occurs when signal shape changes during transmission.

Cause:

  • Different frequencies travel at different speeds.

Types of Encoding

  • Line Encoding
  • Block Encoding
  • Scrambling

Block Encoding

Adds redundancy to improve synchronization and error detection.

Scrambling

Used to avoid long sequences of zeros.

Transmission Modes

Transmission mode refers to the direction of data flow between connected devices.

Types of Transmission

  • Unicast
  • Multicast
  • Broadcast

Unicast

One sender to one receiver communication.

Sender → Receiver

Example:

  • Sending email to one person

Multicast

One sender to multiple selected receivers.

Sender → Receiver1    → Receiver2    → Receiver3

Example:

  • Online streaming to selected users

Broadcast

One sender to all receivers in the network.

Sender → All Devices

Example:

  • ARP Broadcast

Broadcast Types

Limited Broadcasting

Limited broadcast sends packets to all devices in the local network.

IP Address: 255.255.255.255

Direct Broadcasting

Direct broadcast sends packets to all hosts in a specific network.

Example:

  • Network Address + Broadcast Host ID

Network Topology

Network topology refers to the physical or logical arrangement of devices in a network.

Types of Network Topology

  • Bus Topology
  • Star Topology
  • Ring Topology
  • Mesh Topology
  • Hybrid Topology

Bus Topology

All devices connected to a single cable called backbone.

PC1 — PC2 — PC3 — PC4

Advantages

  • Easy to install
  • Low cost

Disadvantages

  • Backbone failure stops entire network
  • Difficult troubleshooting

Star Topology

All devices connected to central hub or switch.

  PC1    | PC2—Switch—PC3    |   PC4

Advantages

  • Easy to manage
  • Failure of one cable does not affect others

Disadvantages

  • Central device failure stops network

Ring Topology

Devices connected in circular structure.

PC1 — PC2 — PC3 |       | PC6 — PC5 — PC4

Advantages

  • Equal access
  • No collision

Disadvantages

  • Single failure breaks network

Mesh Topology

Every device connected to every other device.

PC1 ↔ PC2 ↕  ↕ PC3 ↔ PC4

Advantages

  • High reliability
  • Fault tolerance

Disadvantages

  • Very costly
  • Complex wiring

Hybrid Topology

Combination of two or more topologies.

Example:

  • Star + Bus
  • Star + Ring

Important Note

Star topology is most commonly used in modern LAN networks.

Correction: Modern Ethernet networks mostly use Star topology with switches.

Computer Networks Notes - Part 7 (Internet, Intranet, Extranet)

Internet

Internet is a global network of interconnected computers that communicate using standard protocols like TCP/IP.

  • Type: Public Network
  • Access: Available to everyone
  • Ownership: No single owner
  • Size: Worldwide

Examples:

  • Web browsing
  • Email communication
  • Online services

Intranet

Intranet is a private network used within an organization.

  • Type: Private Network
  • Access: Only authorized users
  • Ownership: Single organization
  • Size: Limited to organization

Examples:

  • Company internal websites
  • Employee portals
  • Office communication systems

Extranet

Extranet is a private network that allows external users limited access to internal resources.

  • Type: Private + External Access
  • Access: Authorized internal and external users
  • Ownership: Single organization
  • Size: Extended private network

Examples:

  • Supplier portals
  • Customer login systems
  • Business partner networks

Difference Between Internet, Intranet, and Extranet

Feature Internet Intranet Extranet

Users Anyone Organization Members Internal + External Users

Important Notes

Internet is the largest network in the world.

Intranet is secure and private.

Extranet extends intranet access to external users.

Correction: Security depends on configuration — Internet itself is not "low security," but public exposure increases risks.

Networking Notes

P2P vs Multipoint

Point-to-Point

  • Direct connection between two devices
  • Dedicated communication link
  • High speed and reliability
  • Example: Connection between two computers using a cable

Multipoint

  • Multiple devices share a single communication link
  • Bandwidth is shared among devices
  • Cost-effective but slower than point-to-point
  • Example: Bus network, shared Wi-Fi channel

Comparison Table

Feature Point-to-Point Multipoint
Devices 2 More than 2
Connection Dedicated Shared
Speed High Moderate
Cost High Low

Networking Notes

Difference: Point-to-Point vs Multipoint Communication

S.NO Point-to-Point Communication Multipoint Communication
1 Point to point communication means the channel is shared between two devices. Multipoint communication means the channel is shared among multiple devices or nodes.
2 There is a dedicated link between two nodes. Link is shared among multiple nodes.
3 The entire capacity is reserved between two devices, which may lead to waste of bandwidth. The capacity is not reserved for any two nodes and bandwidth is efficiently utilized.
4 There is one transmitter and one receiver. There is one transmitter and multiple receivers.
5 The shortest distance is important to reach the receiver. The shortest distance is not important.
6 Provides better security and privacy since the channel is not shared. Less secure and private because the channel is shared.
