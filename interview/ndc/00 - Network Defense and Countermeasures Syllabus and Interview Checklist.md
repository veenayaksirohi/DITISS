### IDS vs IPS

| IDS              | IPS                        |
| ---------------- | -------------------------- |
| Detects attacks  | Detects and blocks attacks |
| Usually passive  | Usually inline             |
| Generates alerts | Can drop malicious traffic |
| Monitoring       | Prevention                 |

### NIDS vs HIDS

| NIDS             | HIDS                          |
| ---------------- | ----------------------------- |
| Network traffic  | Host activity                 |
| Monitors packets | Monitors logs/files/processes |
| Network sensor   | Installed on host             |
| Example: Snort   | Example: OSSEC                |

### Signature vs Anomaly

| Signature Based                | Anomaly Based                   |
| ------------------------------ | ------------------------------- |
| Detects known attacks          | Detects unusual behavior        |
| Uses known signatures          | Uses baseline/behavior          |
| Lower false positives          | May have more false positives   |
| Difficult with unknown attacks | Can detect new/unknown behavior |

# 🎯 Interview Answer Formula

For a normal technical topic:

```text
What is it?
   ↓
How does it work?
   ↓
Why is it used?
   ↓
Real example
```

For a scenario question:

```text
1. Identify the problem
2. Verify using logs/tools
3. Find the affected system
4. Contain the threat
5. Fix the root cause
6. Restore services safely
7. Monitor
8. Prevent recurrence
```

> **Important:** In a scenario interview question, don't answer only with the name of a tool.

Example:

Bad answer:

> "I will use Fail2ban."

Better answer:

> "First I will check SSH authentication logs and confirm repeated failed login attempts. Then I will identify the attacking IP, use Fail2ban or firewall rules to block repeated attempts, harden SSH with key-based authentication and restricted access, and continue monitoring the logs to verify that the attack has stopped."
