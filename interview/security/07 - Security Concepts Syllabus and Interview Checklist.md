# Security Concepts — Interview Checklist

**Duration:** 120 hrs (60T + 50L + 10SL) | **CCEE Module — highest interview weight for security roles**
**Courseware:** Gray Hat Hacking: The Ethical Hackers Handbook (Shon Harris)

---

## Completion Checklist

### Web Application Security
- [ ] OWASP Top 10 (2021)
- [ ] SQL Injection, XSS
- [ ] Burp Suite
- [ ] SAST & DAST tools

### Ethical Hacking
- [ ] Security management concepts & threat classification
- [ ] Cyber crimes / Indian legal aspects
- [ ] Hacking phases & hacker classes (Red/Blue/Grey team)
- [ ] Footprinting, scanning, enumeration
- [ ] Password cracking
- [ ] Trojans, viruses, worms
- [ ] Sniffing, session hijacking
- [ ] DoS/DDoS
- [ ] Web server & wireless hacking
- [ ] Malware reverse engineering

### Mobile Security
- [ ] Android architecture & security model
- [ ] ADB, penetration testing tools
- [ ] OWASP Mobile Top 10
- [ ] MITM, phishing, smishing on mobile
- [ ] Android app static/dynamic analysis (MobSF)

---

## 🔴 Priority 1 — Must Know

- [ ] OWASP Top 10 (2021) — Injection, XSS, Broken Access Control, etc.
- [ ] SQL Injection — time-based, error-based, union-based techniques
- [ ] Burp Suite — Intruder, Repeater, Scanner
- [ ] SAST vs DAST tools (Checkmarx, Fortify, OWASP ZAP)
- [ ] Ethical hacking phases — Recon, Scanning, Gaining Access, Maintaining Access, Covering Tracks
- [ ] Nmap scan types — SYN, Stealth, XMAS, NULL, IDLE, FIN
- [ ] Password cracking — online/offline, John the Ripper, Hydra, rainbow tables
- [ ] Trojans, Viruses, Worms — differences and detection
- [ ] Sniffing — active vs passive, ARP poisoning, MAC flooding
- [ ] DoS vs DDoS — SYN flooding, Smurf attacks, botnets

## 🟠 Priority 2 — Important

- [ ] Session hijacking — spoofing vs hijacking, prevention
- [ ] Wireless security — WEP/WPA/WPA2/WPA3 cracking and defenses
- [ ] Red Team / Blue Team / Grey Team roles
- [ ] IDS/Honeypots/Firewalls (Nagios, Snort as IPS)
- [ ] Malware Reverse Engineering — static vs dynamic analysis
- [ ] Mobile Security — Android architecture, OWASP Mobile Top 10, ADB, rooting risks

## 🟡 Priority 3 — Good to Know

- [ ] Android reverse engineering (APKTool, JADX), MobSF static/dynamic analysis
- [ ] Smishing/phishing attack vectors on mobile
- [ ] Cyber law basics — Indian IT Act, Cyber Crimes, IPC relevance
- [ ] Physical security & penetration testing methodologies (PTES), Metasploit basics
