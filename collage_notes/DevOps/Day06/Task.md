#### **1. Create Virtual Machines using Vagrant**

* Create **two virtual machines** using Vagrant:

  * **Master Node** → Name: `master`
  * **Worker Node** → Name: `worker`

---

#### **2. Install Docker on Both Machines**

* Install Docker on both the `master` and `worker` VMs.
* Ensure Docker service is:

  * Installed successfully
  * Enabled
  * Running properly

---

#### **3. Pull Required Docker Images on Both Machines**


* `httpd`
* `nginx`
* `ubuntu`
* `python`
* `mysql`
* `alpine`
