# storage services

- used to store the data
- types
  - block based storage
    - data will be stored as blocks
    - service: EBS (elastic block storage service)
  - file based storage
    - data will be stored as files
    - service: EFS (elastic file system)
  - object based storage
    - data will be stored as objects
    - service: S3 (simple storage service)

## S3 (simple storage service)

- stores the data as objects
- the objects get stored in buckets
- bucket:
  - container to store the objects
  - every bucket must have a universally unique name
- every object will be using a storage class
- storage class
  - way to store the data
  - decides the costing
  - e.g.
    - standard storage class (costliest and default)
    - Intelligent-Tiering storage class
    - glacier storage class

## bucket creation

- Bucket type: General purpose
- Bucket namespace: Global namespace
- Bucket name: unique bucket name
- Object Ownership : ACLs disabled (recommended)
- Block Public Access settings for this bucket: Block all public access
- Bucket Versioning: Disable
