🐧 Linux Commands Basics — Part 1

📌 Key Concepts

  • Linux commands are case-sensitive.
  • . → Current directory
  • .. → Parent directory
  • ~ → Home directory
  • Hidden files start with .
  • sudo → Run commands with administrator privileges
  • man <command> → Opens manual page
  • Standard Streams:
    • stdin → Standard Input
    • stdout → Standard Output
    • stderr → Standard Error

📂 Navigation Commands

📍 pwd — Print Working Directory

Command Meaning
pwd Show full path of current directory

📁 cd — Change Directory

Command Meaning
cd folder Move into folder
cd .. Go to parent directory
cd ~ Go to home directory
cd - Return to previous directory
cd / Go to root directory

📄 ls — List Files

Command Description
ls List files
ls -l Long listing format
ls -a Show hidden files
ls -la Long listing with hidden files
ls -lh Human readable file sizes
ls -R Recursive listing
💡 TIP: ls -la is commonly used to show full details including hidden files.

🌎 Environment Variables

echo — Print Text or Variables

Command Meaning
echo "Hello" Print text
echo $HOME Show home directory
echo $USER Show username
echo $PATH Show executable path
echo $$ Show process ID

env — Show Environment Variables

Command Description
env Display all environment variables

📁 Directory Management

mkdir — Create Directory

Command Meaning
mkdir dirname Create one directory
mkdir dir1 dir2 Create multiple directories
mkdir -p a/b/c Create nested directories
📌 NOTE: mkdir -p creates parent directories automatically.

rmdir — Remove Empty Directory

Command Description
rmdir dirname Remove empty directory
rmdir dir1 dir2 Remove multiple directories

tree — Show Directory Structure

Command Meaning
tree Show directory structure
tree dirname Show specific directory
tree -a Include hidden files
tree -L 2 Limit depth to 2 levels
📌 NOTE: The tree command may need installation.

🐧 Linux Commands Basics — Part 2

📂 File Management Commands

📄 touch — Create Files

Command Meaning
touch file.txt Create empty file
touch f1.txt f2.txt Create multiple files
touch existing.txt Update timestamp

📖 cat — Display or Write File Content

Command Meaning
cat file.txt Display file content
cat f1.txt f2.txt Display multiple files
cat > file.txt Write new content
cat >> file.txt Append content
cat -n file.txt Show line numbers
cat -b file.txt Number non-empty lines
cat -s file.txt Squeeze blank lines
⚠ WARNING: cat > file.txt will overwrite existing content.

📋 cp — Copy Files and Directories

Command Meaning
cp file.txt copy.txt Copy file
cp file.txt dir1 Copy file to directory
cp file.txt dir1/new.txt Copy and rename
cp -r dir1 copy Copy directory recursively
cp -R folder backup Copy full folder

📦 mv — Move or Rename Files

Command Meaning
mv file.txt new.txt Rename file
mv file.txt dir Move file
mv dir1 dir2 Rename directory
mv file.txt ~/Desktop Move file to location

🔁 rename — Rename Multiple Files

Command Description
rename 's/.txt$/.html/' *.txt Rename all .txt files to .html

🔗 ln — Create Links

Command Meaning
ln file1 hardlink Create hard link
ln -s file1 link Create symbolic link
💡 TIP: Symbolic links behave like shortcuts in Windows.

📡 mkfifo — Create Named Pipe

Command Description
mkfifo fifo Create named pipe

🗑 rm — Remove Files and Directories

Command Meaning
rm file.txt Delete file
rm f1.txt f2.txt Delete multiple files
rm *.txt Delete all txt files
rm -i file.txt Ask before deleting
rm -r dirname Delete directory
rm -rf dirname Force delete
⚠ DANGEROUS COMMAND: rm -rf permanently deletes files without confirmation.
Linux Commands Basics - Part 3

🐧 Linux Commands Basics — Part 3

📖 Viewing and Inspecting File Content

📌 head — Show Beginning of File

Command Meaning
head file.txt Show first 10 lines
head -5 file.txt Show first 5 lines
head -4 file.txt Show first 4 lines
💡 TIP: Use head when you want to quickly preview file contents.

📌 tail — Show End of File

Command Meaning
tail file.txt Show last 10 lines
tail -7 file.txt Show last 7 lines
tail -2 file.txt Show last 2 lines
💡 TIP: tail is very useful for monitoring logs.

📌 wc — Word, Line, and Byte Count

Command Meaning
wc file.txt Show line, word, byte count
wc -l file.txt Show line count
wc -w file.txt Show word count
wc -c file.txt Show byte count
wc -m file.txt Show character count
📌 NOTE: wc is commonly used to count lines in log files.

📌 tac — Reverse Line Order

Command Description
tac file.txt Display lines in reverse order
💡 TIP: tac is reverse of cat.

📌 rev — Reverse Characters in Lines

Command Description
rev file.txt Reverse characters of each line
rev < input.txt Reverse file input
rev > output.txt Save reversed output
📌 NOTE: Use tac for reversing lines and rev for reversing characters.

⭐ Important Combination Example

Command Meaning
head -10 file.txt | tail -5 Show lines 6 to 10 from first 10 lines
⭐ This command is frequently asked in exams.

🐧 Linux Commands Basics — Part 4

🔢 Sorting and Filtering Commands

📌 sort — Sort Lines

Command Meaning
sort file.txt Sort lines alphabetically
sort -n file.txt Sort numerically
sort file.txt > sorted.txt Save sorted output
💡 TIP: Use sort -n when sorting numbers.

📌 uniq — Remove Duplicate Lines

Command Description
uniq file.txt Remove consecutive duplicate lines
sort file.txt | uniq Sort then remove duplicates
📌 NOTE: uniq removes only adjacent duplicates.

🔤 Text Processing Commands

📌 tr — Translate Characters

Command Meaning
echo "Hello SunBeam" | tr " " "#" Replace spaces with #
echo "abc" | tr "a-z" "A-Z" Convert lowercase to uppercase
echo "ABC" | tr "A-Z" "a-z" Convert uppercase to lowercase
tr -s " " Squeeze repeated spaces

📌 cut — Extract Fields

Command Description
cut -d "," -f2 students.csv Extract column 2
cut -d "," -f3,4 students.csv Extract multiple columns
cut -d "," -f2-4 students.csv Extract range of columns

🔁 Pipes and Redirection

📌 Pipes — Send Output to Another Command

Command Meaning
sort file.txt | uniq Send sorted output to uniq
head -10 file.txt | tail -5 Show middle lines
echo "Hello" | tr " " "#" Replace spaces
⭐ Pipe symbol | is heavily used in Linux.

📌 Output Redirection

Command Meaning
command > file.txt Overwrite file output
command >> file.txt Append output
command 2> error.txt Save errors only
command > out.txt 2>&1 Save output and errors together
⚠ WARNING: > overwrites existing file content.

📌 Input Redirection

Command Meaning
command < input.txt Read input from file
bc < input > output Read input and save output

⭐ Important Exam Commands

Command Purpose
sort numbers.txt | uniq Remove duplicate numbers
command > out.txt 2>&1 Store output + errors
head -10 file.txt | tail -5 Extract middle lines
⭐ These combinations are commonly asked in exams.

3 → Library Functions

📌 history — Command History

Command Description

📌 sudo — Run as Administrator

Command Meaning

⭐ sudo is required for most administrative commands.

⭐ Important Commands to Remember

  • sudo → Run as administrator
