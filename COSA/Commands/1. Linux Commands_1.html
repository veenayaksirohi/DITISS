ls Command — Sequential Brief Notes

1. ls Command Definition

The ls (List) command is used in Linux to display the files and directories inside a directory.

Example syntax:

ls [options] [directory_name]

Default behavior:

ls
Lists files and directories in the current directory in alphabetical order.

2. ls -l — Long Listing Format

ls -l shows files in long listing format with detailed information.

ls -l
Example output: 
-rw-r--r-- 1 user group 4096 Apr 5 10:30 file.txt

Linux Shell Notes

🔵 1. .bashrc (Interactive Shell File)

Meaning: Used for interactive, non-login Bash shells

Location: ~/.bashrc

When it runs:

.bashrc runs everytime automatically when you open a new terminal

Purpose: Used to configure interactive terminal behavior

  • Aliases
  • Functions
  • Prompt customization (PS1)
  • Shell options

Example:

alias ll='ls -la'
export PS1="\u@\h:\w$ "

Memory Tip: .bashrc = Every terminal behavior settings

🟡 2. .profile (Login Shell File)

Meaning: Used for login shells

Location: ~/.profile

When it runs: Runs once during login

Purpose: Used for system-wide environment setup

  • Environment variables
  • PATH setup
  • Default programs

Example:

export PATH="$HOME/bin:$PATH"
export EDITOR=vim

Memory Tip: .profile = Login environment setup

🔄 3. Key Differences

Feature .bashrc .profile
Type Interactive shell Login shell
When runs Every terminal Once at login
Purpose Aliases, prompt, functions Environment variables, PATH

🔗 4. Relationship Between Them

Many systems link them using:

if [ -f ~/.bashrc ]; then
    . ~/.bashrc
fi

This ensures login shells also load .bashrc settings

🧠 Final Memory Trick

  • .profile → LOGIN setup
  • .bashrc → TERMINAL behavior setup

4. ls -A — Almost All Files

5. ls -h — Human Readable Size

ls -h shows file sizes in KB, MB, GB.

ls -lh
Example output: 
4.0K    file1.txt
2.3M    video.mp4

6. ls -R — Recursive Listing

ls -R lists files and directories recursively, including subdirectories.

ls -R
Shows: 
dir1:
file1.txt

dir1/subdir:
file2.txt

7. ls -t — Sort by Time

ls -t sorts files by modification time, newest first.

ls -t
- New → Old Reverse order: 
ls -tr
- Old → New

8. ls -S — Sort by Size

ls -S sorts by file size (largest first).

ls -S
Reverse: 
ls -Sr

9. ls -r — Reverse Order

ls -r reverses the default sorting order.

Example: 
ls -r
Order becomes: Z → A

10. ls -i — Show Inode Number

ls -i shows the inode number of each file.

ls -i
Example: 
12345    file1.txt
12346    file2.txt

What is an Inode?

An inode (Index Node) is a unique number assigned to each file that stores its metadata.

Inode stores:

  • File type
  • Permissions
  • Owner
  • Group
  • File size
  • Link count
  • Time details
  • Disk location

Inode does NOT store:

  • File name
  • File data

11. ls -d — List Directory Itself

ls -d shows directory names, not their contents.

ls -d */ shows only directories in the current directory.

Why */ works:

  • *: Matches all names
  • /: Matches directories only
CommandOutput
ls -dShows directory name itself
ls -d */Shows only directories

12. ls --color=auto

ls --color=auto displays files in different colors based on file type.

  • Blue → Directory
  • Green → Executable
  • White → Normal file
