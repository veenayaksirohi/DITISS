These are three common states of data in cybersecurity:

1. **Data at Rest** (sometimes mistakenly written as "data in rest")

   * Data that is stored and not actively moving.
   * Examples:

     * Files on a hard drive
     * Database records
     * Data stored in cloud storage
     * Backups
   * Protection methods:

     * Disk encryption
     * Database encryption
     * Access controls

2. **Data in Transit**

   * Data that is moving between systems, devices, or networks.
   * Examples:

     * Sending an email
     * Browsing a website
     * Data transferred between servers
   * Protection methods:

     * TLS/SSL (HTTPS)
     * VPNs
     * Secure network protocols such as SSH and SFTP

3. **Data in Use** (sometimes called "data being processed")

   * Data that is actively being accessed, processed, or modified in memory.
   * Examples:

     * A document open in a word processor
     * Customer records being processed by an application
     * Data loaded into RAM for computation
   * Protection methods:

     * Memory protection mechanisms
     * Secure enclaves/confidential computing
     * Strong authentication and authorization

### Simple Example

Imagine online banking:

* **Data at Rest:** Your account information stored in the bank's database.
* **Data in Transit:** Your account details traveling between your browser and the bank's server.
* **Data in Use:** The bank's application calculating your account balance after a transaction.

| Data State      | Description             | Example                           |
| --------------- | ----------------------- | --------------------------------- |
| Data at Rest    | Stored data             | Database, files, backups          |
| Data in Transit | Moving data             | HTTPS traffic, emails             |
| Data in Use     | Actively processed data | Data in RAM, running applications |

A complete security strategy protects data in **all three states**.
