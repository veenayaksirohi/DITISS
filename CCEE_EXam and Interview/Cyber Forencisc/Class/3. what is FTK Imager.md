# FTK Imager – Quick Exam Notes

## Definition

**FTK Imager (Forensic Toolkit Imager)** is a digital forensic acquisition tool used to create **forensic images (bit-by-bit copies)** of storage devices without modifying the original evidence.

Developed by [Exterro FTK Imager](https://www.exterro.com/digital-forensics-software/ftk-imager?utm_source=chatgpt.com)

---

## Main Purpose

```text
Original Evidence
       ↓
Create Exact Copy (Image)
       ↓
Analyze the Copy
       ↓
Original Remains Untouched
```

---

## Features

### 1. Disk Imaging

Creates forensic images of:

* Hard Drives
* SSDs
* USB Drives
* Memory Cards

Formats Supported:

* E01 (Most Common)
* RAW/DD
* SMART

---

### 2. Hash Verification

Generates:

* MD5
* SHA-1
* SHA-256

Used to verify evidence integrity.

```text
Original Hash = Image Hash
```

Evidence has not been altered.

---

### 3. File Preview

View:

* Documents
* Images
* Videos
* Deleted Files

without changing evidence.

---

### 4. RAM Capture

Can capture:

* Running Processes
* Network Connections
* Malware in Memory
* Encryption Keys

Menu:

```text
File → Capture Memory
```

---

### 5. Recover Deleted Files

Can access:

* Deleted Files
* Unallocated Space
* Slack Space

---
