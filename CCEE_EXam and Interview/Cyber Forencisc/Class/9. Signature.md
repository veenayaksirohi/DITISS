Antivirus Works on signature 

Yes, **traditional antivirus primarily works on signatures**.

### What is a Signature?

A signature is a unique pattern or fingerprint of known malware, such as:

* File hashes (MD5, SHA-256)
* Specific byte sequences
* Known malicious code patterns
* Malware identifiers

### How Signature-Based Detection Works

```text
File Scanned
      ↓
Compare with Malware Signature Database
      ↓
Match Found?
   ↙        ↘
 Yes         No
  ↓           ↓
Malware    Considered Safe
Detected   (or further checks)
```

### Example

Suppose a malware file has the hash:

```text
SHA256:
a1b2c3d4...
```

The antivirus database contains the same hash.

```text
File Hash = Database Hash
         ↓
 Malware Detected
```

---

## Limitations of Signature-Based Detection

❌ Cannot detect:

* New (zero-day) malware
* Modified malware variants
* Polymorphic malware
* Metamorphic malware

Attackers often change malware slightly so its signature changes.

---

## Modern Antivirus Uses More Than Signatures

Today's antivirus solutions combine:

| Technique                 | Purpose                                  |
| ------------------------- | ---------------------------------------- |
| Signature-Based Detection | Detect known malware                     |
| Heuristic Analysis        | Detect suspicious code patterns          |
| Behavioral Analysis       | Monitor actions at runtime               |
| Sandboxing                | Execute files in an isolated environment |
| Machine Learning          | Identify previously unseen threats       |
| Cloud Intelligence        | Check reputation using cloud databases   |

---

## Signature vs Heuristic Detection

| Signature-Based       | Heuristic-Based                   |
| --------------------- | --------------------------------- |
| Detects known malware | Detects unknown malware           |
| Fast                  | Slower                            |
| Low false positives   | Higher false positives            |
| Requires updates      | Can work without exact signatures |

---

### Exam/Viva Question

**Q: Does antivirus work only on signatures?**

**Answer:** No. Traditional antivirus relied mainly on signature-based detection, but modern antivirus solutions also use heuristics, behavior monitoring, sandboxing, machine learning, and cloud-based threat intelligence to detect both known and unknown malware.
