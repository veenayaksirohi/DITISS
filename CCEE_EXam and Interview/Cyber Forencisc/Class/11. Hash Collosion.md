## Hash Collision

A hash collision occurs when two different inputs produce the same hash value.

Example:

File A ≠ File B

MD5(File A) = MD5(File B)

### Why MD5 is Not Recommended

* 128-bit hash algorithm
* Vulnerable to collision attacks
* Can produce the same hash for different files

### Preferred Algorithms

* SHA-256
* SHA-512

### Forensics Best Practice

* Calculate SHA-256 before transfer
* Calculate SHA-256 after transfer
* Compare hashes to verify integrity

### One-Line Exam Answer

A hash collision occurs when two different inputs generate the same hash value. MD5 is vulnerable to collisions, so SHA-256 is preferred in digital forensics.
