Cyber Forensics Investigation Process
1. Identification
2. Preservation
3. Collection 
4. Exmination 
5. Analysis
6. Reporting 
7. Presentation

1. Identification

Identify potential sources of evidence.

Examples:

Hard Drives
Mobile Phones
Servers
Cloud Storage
USB Devices


2. Preservation

Protect evidence from modification.

Methods:

Write Blockers
Disk Imaging
Hash Verification

3. Collection

Gather evidence securely.

Examples:

Memory Dump
Log Files
Network Traffic Capture

4. Examination

Extract relevant information.

Activities:

File Recovery
Metadata Analysis
Timeline Creation

5. Analysis

Determine what happened.

Questions:

Who performed the action?
When did it happen?
How was it done?
What was affected?

6. Reporting

Prepare investigation report.

Include:

Findings
Evidence
Screenshots
Hash Values
Conclusions

7. Presentation
Present findings to management or court.
