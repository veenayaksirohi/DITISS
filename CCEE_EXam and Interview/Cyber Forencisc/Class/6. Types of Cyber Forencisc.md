Types of Cyber Forensics

1. Computer Forensics
Investigation of computers and storage devices.
Focus:
Deleted Files
Registry Analysis
User Activity

2. Network Forensics
Analysis of network traffic.
Focus:
Packet Captures
IDS Logs
Firewall Logs

Tools:

Wireshark
Tcpdump
Snort
3. Mobile Forensics

Investigation of smartphones and tablets.

Focus:

SMS
Call Logs
Contacts
App Data
GPS Data

Tools:

Cellebrite
Autopsy
MOBILedit
4. Database Forensics

Investigation of databases.

Focus:

SQL Logs
Deleted Records
Unauthorized Access
5. Email Forensics

Investigation of email communications.

Focus:

Email Headers
Attachments
Spoofing Detection
6. Cloud Forensics

Investigation of cloud environments.

Focus:

Cloud Logs
Virtual Machines
User Activities
7. Malware Forensics

Investigation of malicious software.

Focus:

Malware Behavior
Persistence Mechanisms
Command and Control Communication

Tools:

REMnux
Cuckoo Sandbox
YARA
