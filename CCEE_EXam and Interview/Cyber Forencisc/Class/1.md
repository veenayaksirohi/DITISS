# Digital Forensics

1. Identification, Preservation, Analysis of Digital Evidence from computer systems and networks.

2. Legally Compliant Documentation is required for further proceedings.

3. It involves forensic analysis of data on storage (distributed and non-distributed) and computer networks.

4. **Live System Forensics**

   * Forensics of a live system where the incident is still going on.
   * Acquisition and analysis of volatile data.
   * Forensics of a live system but disconnected from the network.

5. **Offline Forensics (Post-Mortem Forensics)**

   * Examination of disk images.
   * Recovery and analysis of deleted files.

   A. **Data Forensics**

   * Team is going to validate and analyze the data generated from applications.

   B. **Disk Forensics**

   * Investigation of computers or mobile devices and their stored data.

## 1. Chain of Custody

### Create Evidence Record

Create the following fields:

* Case ID
* Evidence ID
* Description
* Date and Time
* Hash Value

| Field        | Description                |
| ------------ | -------------------------- |
| Case Number  | Investigation ID           |
| Evidence ID  | Unique evidence number     |
| Description  | Details of evidence        |
| Date & Time  | When collected/transferred |
| Location     | Where evidence was found   |
| Collected By | Investigator name          |
| Received By  | Person taking custody      |
| Purpose      | Reason for transfer        |
| Signatures   | Verification of transfer   |

### Transfer Log

Record:

* From
* To
* Date
* Purpose of Transfer

### Secure Storage

* Store evidence in a read-only drive.
* Maintain evidence securely.

### Importance

Chain of Custody must always be maintained to ensure:

* Legal Admissibility
* Accountability
* Evidence Integrity

## Principles of Cyber Forensics

### 1. Preservation

Original evidence must be protected from alteration or damage.

Best Practices:

* Use Write Blockers.
* Never analyze the original disk.
* Create a forensic image.
* Mount images as read-only.
* Perform analysis on copies only.

### 2. Data Integrity

Use cryptographic hashing to preserve data integrity.

Best Practices:

* Use strong hashing algorithms such as SHA-256.
* Calculate hashes before and after transfer.
* Verify hashes regularly.

Note:

* MD5 is discouraged because of hash collision vulnerabilities.
* MD5 is considered deprecated for forensic integrity verification.

### 3. Chain of Custody

Maintain documentation of every person who handles evidence and every transfer that occurs.

### Important Note

**Do not perform any modification on the original evidence.**

## 4. Forensic Imaging

Creates an exact bit-by-bit copy of:

* Hard Drives
* SSDs
* USB Drives
* Memory Cards
* CD/DVD Media

### Supported Formats

| Format   | Description                 |
| -------- | --------------------------- |
| RAW (dd) | Bit-by-bit image            |
| E01      | EnCase Evidence Format      |
| SMART    | Proprietary forensic format |
| AFF      | Advanced Forensic Format    |

## 5. Documentation

Maintain complete records of:

* Evidence Collection
* Imaging Process
* Hash Values
* Analysis Procedures
* Findings
* Reports

---

## 6. Reproducibility

The forensic process should be repeatable.

Another investigator should be able to:

* Follow the same procedure
* Verify the same evidence
* Obtain the same results

---

## 7. Legal Compliance

Ensure all forensic activities comply with:

* Organizational Policies
* Legal Requirements
* Regulatory Standards
* Court Procedures

This ensures evidence remains admissible during investigations and legal proceedings.
