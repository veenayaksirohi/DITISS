# File System Checking and Repair (RHEL)

RHEL provides utilities to check and repair file systems. These are commonly called `fsck` tools. They ensure metadata consistency but are **not data recovery tools**.  

## When to Check a File System
- System fails to boot  
- Disk files become corrupt  
- File system switches to read-only  
- Files are inaccessible  

**Note:** Hardware errors must be resolved first (e.g., using `dd`) for repair to work.  

---

## Potential Side Effects
- Severely damaged inodes/directories may be discarded  
- Significant file system changes may occur  

---

## XFS Error Handling
- **Unclean unmounts:** journal recovery occurs automatically at mount time  
- **Corruption:** caused by hardware faults, bugs, or overwrites outside the FS  
- **Symptoms:** failed mounts, I/O errors, “Structure needs cleaning”
