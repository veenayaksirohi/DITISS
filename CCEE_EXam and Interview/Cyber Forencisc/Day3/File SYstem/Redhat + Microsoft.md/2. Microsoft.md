# Windows File Recovery - Notes

## Overview

Windows File Recovery is a command-line utility provided by Microsoft that helps recover deleted files from:

- Internal Hard Drives (HDD)
- Solid State Drives (SSD)
- External Hard Drives
- USB Drives

It is useful when files:

- Are deleted permanently
- Cannot be restored from the Recycle Bin
- Are lost after formatting or corruption

> Note: Recovery from cloud storage and network shares is not supported.

---

# Important Recovery Tips

To maximize recovery success:

1. Stop using the affected drive immediately.
2. Avoid installing software on the same drive.
3. Avoid creating or copying new files.

### Why?

When a file is deleted, Windows marks its storage space as free.

The actual data may still exist until new data overwrites it.

---

# Supported File Systems

| File System | Common Usage |
|------------|-------------|
| FAT | Small USB drives, SD cards |
| exFAT | Flash drives and SD cards |
| NTFS | Windows HDDs and SSDs |

### Check File System

1. Open File Explorer
2. Right-click the drive
3. Select **Properties**
4. View the **File System** field

---

# Recovery Modes

## Regular Mode

Used when:

- File system is NTFS
- File was deleted recently
- Drive is healthy

### Advantages

- Faster
- Best for recent deletions

---

## Extensive Mode

Used when:

- File deleted long ago
- Disk formatted
- Disk corrupted
- FAT/exFAT drives

### Advantages

- More thorough scanning
- Supports all file systems

---

# Mode Selection Table

| File System | Situation | Mode |
|------------|------------|------|
| NTFS | Deleted Recently | Regular |
| NTFS | Deleted Long Ago | Extensive |
| NTFS | Formatted Disk | Extensive |
| NTFS | Corrupted Disk | Extensive |
| FAT/exFAT | Any Situation | Extensive |

# Basic Command Syntax

```cmd
winfr source-drive: destination-drive: [mode] [switches]
```

### Example

```cmd
winfr C: D: /regular
```

Recover files from drive C: and save recovered files to drive D:.

---

# General Parameters

## Source Drive

```cmd
C:
```

Drive where files were lost.

---

## Destination Drive

```cmd
D:
```

Drive where recovered files will be saved.

> Source and Destination drives must be different.

---

# Common Switches

## /regular

Use Regular recovery mode.

```cmd
winfr C: D: /regular
```

---

## /extensive

Use Extensive recovery mode.

```cmd
winfr C: D: /extensive
```

---

## /n

Search using filename, path, or wildcard.

### Recover a specific file

```cmd
/n report.docx
```

### Recover all DOCX files

```cmd
/n *.docx
```

### Recover files from a folder

```cmd
/n \Users\User\Documents\
```

---

## /?

Show help information.

```cmd
winfr /?
```

---

## /!

Display advanced help.

```cmd
winfr /!
```

---

# Advanced Recovery Modes

## NTFS Mode

```cmd
/ntfs
```

Fast recovery using Master File Table (MFT).

Suitable for healthy NTFS volumes.

---

## Segment Mode

```cmd
/segment
```

Uses File Record Segments (FRS).

Useful when MFT information is partially available.

---

## Signature Mode

```cmd
/signature
```

Recovers files using file headers/signatures.

Works on all file systems.

Useful when metadata is damaged.

---

# Advanced Switches

## Recover Specific File Types

```cmd
/y:JPEG,PNG
```

Recover only specified file extensions.

---

## View Supported Signatures

```cmd
/#
```

Lists supported file groups.

---

## Save Recovery Log

```cmd
/p:D:\Logs
```

Stores recovery logs in a custom location.

---

## Automatic Confirmation

```cmd
/a
```

Suppresses prompts.

Useful for scripts.

---

## Recover Undeleted Files

```cmd
/u
```

Attempts recovery of undeleted files.

Supported:

- NTFS
- Segment Mode

---

## Recover System Files

```cmd
/k
```

Includes Windows system files.

---

## Overwrite Options

```cmd
/o:a
```

Always overwrite.

```cmd
/o:n
```

Never overwrite.

```cmd
/o:b
```

Keep both copies.

---

## Recover Files Without Data Streams

```cmd
/g
```

Useful in specific NTFS recovery scenarios.

---

## Disable File Type Filtering

```cmd
/e
```

Shows all file types.

---

## Exclude Specific File Types

```cmd
/e:txt
```

Filter specific extensions.

---

## Specify Sector Count

```cmd
/s:<sectors>
```

Used in Segment and Signature modes.

---

## Specify Cluster Size

```cmd
/b:<bytes>
```

Defines allocation unit size.

### What is Windows File Recovery?

A Microsoft command-line tool used to recover deleted files from local storage devices.

### Which mode is faster?

Regular Mode.

### Which mode is more thorough?

Extensive Mode.

### Which file system is most common in Windows?

NTFS.

### Can it recover files from cloud storage?

No.

Yes, using Extensive Mode.
