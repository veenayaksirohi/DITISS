# File System

A File System is responsible for managing how data is stored, organized, accessed, and maintained on a storage device.

## Core Functions of a File System

### 1. Store

The file system organizes data into files and directories and manages where the data is physically stored on the storage device (HDD, SSD, etc.).

**Responsibilities:**

* Create and manage files
* Organize files into directories/folders
* Allocate storage space on disk
* Maintain file metadata (name, size, permissions, timestamps)

### 2. Recover

The file system ensures that data remains consistent and recoverable after unexpected events such as power failures, system crashes, or hardware issues.

**Responsibilities:**

* Detect and repair file system errors
* Recover from crashes
* Maintain data integrity
* Support recovery mechanisms such as journaling

### 3. Track Changes

The file system manages changes made to files and controls how data moves from temporary memory (RAM) to permanent storage.

**Responsibilities:**

* Monitor file modifications
* Manage write operations
* Handle caching and buffering
* Ensure data is safely written to disk

## Summary

| Function      | Purpose                                                    |
| ------------- | ---------------------------------------------------------- |
| Store         | Organizes and stores files and directories on disk         |
| Recover       | Restores file system consistency after crashes or failures |
| Track Changes | Manages updates and writes data from memory to storage     |

### Quick Notes

* **Store** → Organize and save data.
* **Recover** → Restore data after failures.
* **Track Changes** → Manage and record file updates.
