# Disk Imaging Notes

## Disk Image

A disk image is a bit-by-bit copy of a storage device or partition.

### OS Running

🔴 **Inconsistent Image**

* Files may be changing during acquisition.
* Cached data may not be written to disk.
* Can contain partially written files.

### OS Paused / Shut Down

🟢 **Consistent Image**

* No active disk writes.
* File system remains stable.
* More reliable for forensic analysis.

## Quick Note

```text
OS Running      → Inconsistent Image
OS Paused       → Consistent Image

Reason:
Active writes during imaging can alter data,
while a paused system provides a stable disk state.
```
