# 1. Standard Operating Procedures (SOP)

## Definition

A **Standard Operating Procedure (SOP)** is a documented set of instructions that guides forensic investigators in collecting, preserving, analyzing, and presenting digital evidence in a consistent and legally acceptable manner.

### Objectives of SOP

* Ensure evidence integrity.
* Maintain chain of custody.
* Ensure repeatable investigations.
* Reduce human errors.
* Meet legal requirements.
* Improve efficiency.

---

# Components of SOP

## 1. Preparation

Before incident handling:

* Incident Response Plan
* Forensic Toolkit Ready
* Write Blockers Available
* Storage Media Available
* Documentation Templates Ready
* Legal Authorization Obtained

### Important Point

Preparation determines investigation success.

---

## 2. Identification

Identify:

* Nature of Incident
* Affected Systems
* Scope of Compromise
* Type of Evidence

Examples:

* Malware Infection
* Insider Threat
* Data Theft
* Unauthorized Access

---

## 3. Preservation

Goal:
Prevent evidence alteration.

Methods:

* Disconnect Network
* Avoid unnecessary system interaction
* Use Write Blockers
* Create Bit-by-Bit Copies

### Golden Rule

**Never work on original evidence.**

Always work on forensic copies.

---

## 4. Collection

Collect:

* Hard Disk Images
* RAM Dumps
* Logs
* Network Traffic
* Registry Files
* Browser Artifacts

Tools:

* FTK Imager
* EnCase
* Magnet Acquire
* DumpIt
* Belkasoft RAM Capturer

---

## 5. Examination

Activities:

* Keyword Search
* Timeline Analysis
* Log Analysis
* File Recovery
* Malware Detection

---

## 6. Analysis

Determine:

* What happened?
* When did it happen?
* How did it happen?
* Who did it?
* What was affected?

---

## 7. Documentation

Document:

* Date and Time
* Investigator Name
* Tools Used
* Findings
* Evidence Details

---

## 8. Reporting

Final report contains:

* Executive Summary
* Methodology
* Findings
* Screenshots
* Timeline
* Conclusion

# Order of Volatility (OOV)

Collect most volatile data first.

## Highest Volatility

1. CPU Registers
2. Cache
3. RAM
4. Network Connections
5. Running Processes
6. Disk Data
7. Archives

### Memory Changes Quickly

RAM acquisition should occur first.

---

# Live Acquisition

## Definition

Collecting evidence while system is running.

### Examples

* RAM Capture
* Active Network Connections
* Running Processes

### Advantages

* Captures volatile evidence

### Disadvantages

* May alter system state

---

# Dead Acquisition

## Definition

Collecting evidence after shutdown.

### Advantages

* Less risk of altering data

### Disadvantages

* Volatile data lost

## Event Logs

Location:

```text
C:\Windows\System32\winevt\Logs
```

Types:

### Security Log

* Login Attempts
* Account Changes

### System Log

* System Events

### Application Log

* Application Activities

---

## Prefetch Files

Location:

```text
C:\Windows\Prefetch
```

Purpose:

Shows executed programs.

Extension:

```text
.pf
```

---

Stores deleted files.

Useful for:

* User Activity Tracking

---

## Recent Files

Location:

# DOS Commands Useful in Forensics

DOS = Disk Operating System Command Line

---

# System Information

```cmd
systeminfo
```

Displays:

* OS Version
* Installed Updates
* Host Name

---

# User Information

```cmd
whoami
```

Displays current user.

---

# Active Sessions

```cmd
query user
```

Displays logged-in users.

---

# Network Information

```cmd
ipconfig /all
```

Shows:

* IP Address
* MAC Address
* DNS Information

---

# Active Connections

```cmd
netstat -ano
```

Shows:

* Open Ports
* Active Connections
* PID

---

# Running Processes

```cmd
tasklist
```

Lists active processes.

---

# Process Termination

```cmd
taskkill /PID 1234 /F
```

Terminates process.

---

# User Accounts

```cmd
net user
```

Lists local users.

---

# Shared Resources

```cmd
net share
```

Lists shared folders.

---

# ARP Cache

```cmd

```

Displays network mappings.

---

# Routing Table

```cmd

```

Displays network routes.

---

# Open Files

```cmd
openfiles
```

Lists opened files.

---

# Registry Query

```cmd

```

Used to examine registry entries.

# File Hash Verification

```cmd
certutil -hashfile file.txt SHA256
```
