# UNIT 1: Live System Forensics (Active State Forensics)

## What is Live Forensics?

Live Forensics is the process of collecting and analyzing digital evidence from a computer system while it is still powered on and running.

Unlike traditional forensic investigations where the system is shut down and analyzed, live forensics focuses on volatile data that disappears when power is removed.

### Why Live Forensics?

Important evidence exists only in memory:

* Running processes
* Active network connections
* Logged-in users
* Encryption keys
* Open files
* Clipboard data
* Unsaved documents
* Malware running in memory

---

## Live Data vs Static Data

| Live Data (Volatile) | Static Data (Non-Volatile) |
| -------------------- | -------------------------- |
| RAM                  | Hard Disk                  |
| Running Processes    | Logs                       |
| Network Connections  | Documents                  |
| Cache                | Registry Files             |
| Open Ports           | Databases                  |

### Order of Volatility

Evidence should be collected in the following order:

1. CPU Registers
2. Cache
3. RAM
4. Network Connections
5. Running Processes
6. Disk Data
7. Backups

**Exam Point:** Collect the most volatile evidence first.

---

### Step 1: Preparation

### Step 2: Live Evidence Collection

### Step 4: Analysis

### Step 5: Reporting

Prepare detailed forensic report.

## Memory Analysis using Volatility

### Common Commands

#### Image Information

```bash
vol.py -f memory.raw windows.info
```

#### Process List

```bash
vol.py -f memory.raw windows.pslist
```

#### Process Tree

```bash
vol.py -f memory.raw windows.pstree
```

#### Network Connections

```bash
vol.py -f memory.raw windows.netstat
```

#### Command History

```bash
vol.py -f memory.raw windows.cmdline
```

#### DLL List

```bash
vol.py -f memory.raw windows.dlllist
```

#### User Sessions

```bash
vol.py -f memory.raw windows.sessions
```
