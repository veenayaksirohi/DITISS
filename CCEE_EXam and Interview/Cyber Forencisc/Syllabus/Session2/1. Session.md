# Cyber Forensics Complete Notes

# 1. Introduction to Cyber Forensics

## Definition

Cyber Forensics (Digital Forensics) is the process of identifying, preserving, collecting, examining, analyzing, and presenting digital evidence in a legally acceptable manner.

It helps investigators determine:

* What happened?
* How did it happen?
* Who performed the action?
* When did it happen?
* What was affected?

---

## Objectives of Cyber Forensics

1. Identify digital evidence.
2. Preserve evidence without modification.
3. Recover deleted or hidden information.
4. Analyze malicious activities.
5. Reconstruct events.
6. Present findings in court or investigations.

---

# 2. Computer Forensics Involves

## 1. Preservation

### Definition

Protecting evidence from alteration, damage, or destruction.

### Activities

* Disconnect affected systems carefully.
* Create forensic images.
* Maintain evidence integrity.
* Use write blockers.

### Importance

Evidence must remain unchanged.

### Example

Creating a bit-by-bit image using:

* FTK Imager
* EnCase
* dd

---

## 2. Identification

### Definition

Recognizing potential sources of evidence.

### Sources

* Hard drives
* SSDs
* USB drives
* Memory dumps
* Mobile phones
* Network logs
* Cloud storage

### Example

Identifying suspicious executable files on Windows.

---

## 3. Extraction

### Definition

Collecting and recovering data from evidence.

### Data Types

* Active files
* Deleted files
* Hidden files
* Log files
* Registry entries
* Browser history

### Tools

* Autopsy
* FTK
* Volatility
* Sleuth Kit

---

## 4. Documentation

### Definition

Recording every action during investigation.

### Includes

* Investigator name
* Date and time
* Tools used
* Evidence collected
* Findings

### Importance

Maintains credibility and chain of custody.

---

## 5. Interpretation

### Definition

Analyzing evidence and deriving conclusions.

### Example

Finding that malware was executed through a malicious email attachment.

---

# 3. Goals of Forensic Analysis

## Primary Goals

### 1. Evidence Collection

Gather digital evidence safely.

### 2. Evidence Preservation

Prevent alteration.

### 3. Incident Reconstruction

Determine sequence of events.

### 4. Attribution

Identify responsible individual or system.

### 5. Reporting

Present findings clearly.

### 6. Legal Admissibility

Ensure evidence is accepted in court.

# 4. Types of Cyber Forensics

---

## 1. Disk Forensics

Analyzing storage devices.

### Evidence

* Deleted files
* MFT entries
* Partition information

### Tools

* FTK Imager
* Autopsy
* EnCase

---

## 2. Memory Forensics

Analyzing RAM dumps.

### Evidence

* Running processes
* Network connections
* Injected malware
* Encryption keys

### Tools

* Volatility
* Rekall

### Example Commands

```bash
vol.py -f memory.raw windows.pslist
vol.py -f memory.raw windows.netscan
```

---

# 5. Cyber Forensics Procedure

---

## Phase 1: Identification

Find relevant evidence.

### Example

Locate suspicious executable.

---

## Phase 2: Preservation

Prevent evidence modification.

### Example

Create forensic image.

---

## Phase 3: Collection

Acquire data.

### Examples

* Disk image
* Memory image
* Logs

---

## Phase 4: Examination

Process evidence.

### Examples

* Recover deleted files
* Extract logs

---

## Phase 5: Analysis

Interpret evidence.

### Examples

* Malware execution timeline
* User activity timeline

---

## Phase 6: Reporting

Document findings.

### Include

* Evidence
* Methodology
* Results
* Conclusion

# 9. Detecting Incidents

## Indicators of Compromise (IOCs)

### Host-Based

* Unknown processes
* High CPU usage
* Unauthorized accounts

### Network-Based

* Suspicious traffic
* Unexpected DNS requests
* Connections to malicious IPs

### Log-Based

* Failed logins
* Privilege escalation
* Account lockouts

## Definition

---

## Purpose

Maintains integrity and admissibility.

---

## Information Recorded

* Description
* Date and time
* Collector
* Location
* Transfers

---

# Chain of Custody Principles

### Accountability

Every handler identified.

### Traceability

Every transfer recorded.

### Integrity

Evidence remains unchanged.

### Security

Evidence protected.
