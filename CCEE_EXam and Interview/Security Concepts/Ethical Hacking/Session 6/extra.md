| Data State          | One-Line Definition                                                                      |
| ------------------- | ---------------------------------------------------------------------------------------- |
| **Data at Rest**    | Data that is stored on a device, database, or storage system and is not actively moving. |
| **Data in Transit** | Data that is being transferred between systems, devices, or networks.                    |
| **Data in Use**     | Data that is actively being accessed, processed, or modified by an application or user.  |

### Simple Examples

| Data State          | Example                                               |
| ------------------- | ----------------------------------------------------- |
| **Data at Rest**    | A file saved on a hard drive.                         |
| **Data in Transit** | An HTTPS request sent from a browser to a web server. |
| **Data in Use**     | Data loaded into RAM while an application is running. |
