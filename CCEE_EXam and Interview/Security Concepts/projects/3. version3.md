# PHASE 6 — IOC ENGINE

IOC = Indicator Of Compromise

Create:

```text

```

Example:

```text

1.2.3.4
```

---

Create:

```bash
ioc_checker.sh
```

Logic:

```bash
Extract source IP
Compare with bad_ips.txt
Generate alert
```

Pseudo:

```bash
if IP in IOC
then
HIGH ALERT
fi
```

# PHASE 12 — CUSTOM SNORT RULES

Edit:

```bash
sudo nano /etc/snort/rules/local.rules
```

Rule 1

```text
alert icmp any any -> any any
(msg:"PING DETECTED";
sid:1000001;
rev:1;)
```

---

Rule 2

```text
alert tcp any any -> $HOME_NET 22
```
