# Resume Description

**Linux Security Audit & Threat Monitoring Framework**

> Developed a Bash-based Linux Security Audit and Threat Monitoring Framework capable of auditing user privileges, firewall configurations, password policies, and open ports while detecting brute-force attacks, unauthorized access attempts, and privilege escalation events through real-time log analysis and automated alert generation. This project leveraged Linux administration, Bash scripting, cron automation, networking, and security monitoring concepts to improve system visibility and incident detection.
