# Denial of Service (DoS) Attack – Complete Theory & Practical Notes

---

# 1. What is Denial of Service (DoS)?

A **Denial of Service (DoS)** attack is a cyberattack in which an attacker attempts to make a system, server, network, application, or service unavailable to legitimate users by exhausting its resources.

The objective is not to steal data but to:

* Disrupt services
* Slow down systems
* Crash applications
* Consume bandwidth
* Exhaust CPU, RAM, Disk, or Network resources

---

# 2. Definition

> A Denial of Service attack is an attempt to make a computer system or network resource unavailable to intended users by overwhelming it with malicious traffic or resource requests.

---

# 3. Types of DoS Attacks

## A. Volume-Based Attacks

Goal:

* Consume network bandwidth

Examples:

| Attack               | Description                          |
| -------------------- | ------------------------------------ |
| UDP Flood            | Large number of UDP packets          |
| ICMP Flood           | Massive ping requests                |
| Amplification Attack | Reflection using third-party servers |

Target:

* Network bandwidth

---

## B. Protocol Attacks

Goal:

* Exploit weaknesses in network protocols

Examples:

| Attack               | Description                |
| -------------------- | -------------------------- |
| SYN Flood            | Half-open TCP connections  |
| Ping of Death        | Oversized ICMP packets     |
| Smurf Attack         | ICMP broadcast abuse       |
| Fragmentation Attack | Malformed packet fragments |

Target:

* Firewalls
* Routers
* Load balancers

---

## C. Application Layer Attacks

Goal:

* Exhaust application resources

Examples:

| Attack          | Description                    |
| --------------- | ------------------------------ |
| HTTP GET Flood  | Massive webpage requests       |
| HTTP POST Flood | Resource-intensive submissions |
| Slowloris       | Keeps connections open         |
| DNS Query Flood | DNS server overload            |

Target:

* Web servers
* Databases
* APIs

---

# 4. DoS vs DDoS

| Feature        | DoS           | DDoS             |
| -------------- | ------------- | ---------------- |
| Attack Source  | Single system | Multiple systems |
| Traffic Volume | Limited       | Very High        |
| Detection      | Easier        | Harder           |
| Cost           | Low           | High             |
| Impact         | Moderate      | Severe           |

# 9. SYN Flood Attack

One of the most common DoS attacks.

---

## Working

Attacker sends many SYN packets.

```text
Attacker -> SYN

Server -> SYN-ACK

(No ACK)
```

Server waits.

Thousands of half-open connections accumulate.

---

## Result

* Connection table becomes full.
* Legitimate users cannot connect.

---

## Diagram

```text
Attacker

SYN ------>
SYN ------>
SYN ------>
SYN ------>

Server

SYN-ACK
(waiting)

SYN-ACK
(waiting)
```

---

## Detection

Wireshark Filter:

```text
tcp.flags.syn == 1 && tcp.flags.ack == 0
```

---

## Mitigation

* SYN Cookies
* Rate limiting
* Firewall filtering
* Load balancing

---

# 10. UDP Flood

Attacker sends massive UDP packets.

---

## Working

```text
Attacker ---> UDP Packet
Attacker ---> UDP Packet
Attacker ---> UDP Packet
```

Server processes each packet.

CPU utilization increases.

---

## Symptoms

* High bandwidth usage
* Packet loss
* Slow response

---

## Detection

Wireshark:

```text
udp
```

---

## Mitigation

* Rate limiting
* Firewall ACLs
* IDS/IPS

---

# 11. ICMP Flood (Ping Flood)

Attacker sends excessive ICMP Echo Requests.

---

## Working

```text
Ping
Ping
Ping
Ping
Ping
```

Target spends resources replying.

---

## Detection

Wireshark:

```text
icmp
```

---

## Mitigation

* Disable unnecessary ICMP
* Rate limiting
* Firewall filtering

---

# 12. Smurf Attack

A reflection-based DoS attack.

---

## Working

Attacker spoofs victim IP.

```text
Victim IP spoofed
        |
Broadcast Network
        |
Many Hosts Reply
        |
Victim Overwhelmed
```

---

## Result

Amplified traffic.

---

## Mitigation

* Disable IP-directed broadcasts
* Anti-spoofing

---

# 13. Ping of Death

Attacker sends malformed oversized ICMP packets.

---

## Packet Size

Normal:

```text
65535 bytes maximum
```

Exceeds limit after fragmentation.

---

## Effect

* System crash
* Reboot
* Freeze

Mostly historical today.

---

# 14. Teardrop Attack

Uses overlapping IP fragments.

---

## Working

Malformed fragments confuse reassembly process.

```text
Fragment A
Fragment B overlaps A
```

---

## Result

* Crash
* Memory corruption

Mostly affects legacy systems.

---

# 15. LAND Attack

Local Area Network Denial Attack.

---

## Working

Source IP = Destination IP

```text
Src: Victim
Dst: Victim
```

System replies to itself repeatedly.

---

## Result

Resource exhaustion.

Mostly historical.

---

# 16. Slowloris Attack

Application-layer DoS.

---

## Working

1. Open many HTTP connections.
2. Send partial headers.
3. Never complete request.

Example:

```http
GET / HTTP/1.1
Host: victim.com
X-a: 1
```

Keep sending tiny headers.

Server keeps connections alive.

---

## Result

* Connection pool exhaustion
* Website unavailable

---

## Detection

Many open connections from few IPs.

---

## Mitigation

* Reverse proxy
* Timeout configuration
* Load balancing

---

# 17. HTTP GET Flood

Attacker sends massive GET requests.

---

## Example

```http

GET /
GET /
GET /
```

---

## Result

# 18. HTTP POST Flood

More dangerous than GET Flood.

---

## Why?

* Database queries

Consumes more resources.

# 19. DNS Flood Attack

Target:

DNS servers.

---

## Working

Thousands of DNS queries.

```text
Query
Query
Query
Query
```

---

## Result

DNS service becomes unavailable.

---

# 20. DNS Amplification Attack

Reflection + Amplification.

---

## Working

Attacker spoofs victim IP.

Sends small DNS request.

DNS server sends large response.

Example:

```text
60-byte request
4000-byte response
```

Amplification achieved.

---

## Diagram

```text
Attacker
    |
Small DNS Query
    |
DNS Server
    |
Large Reply
    |
Victim
```

---

# 21. NTP Amplification

Uses Network Time Protocol servers.

Small request.

Huge response.

Amplification factor can be very high.

---

# 22. SSDP Amplification

Uses:

* UPnP devices
* IoT devices

Frequently used in DDoS campaigns.

---

# 23. Reflection Attack

Definition:

Attacker causes third-party servers to send traffic to victim.

Examples:

* DNS Reflection
* NTP Reflection
* SSDP Reflection

---

# 24. Amplification Attack

Definition:

Small request generates much larger response.

---

## Formula

Amplification\ Factor=\frac{Response\ Size}{Request\ Size}

Example:

```text
50-byte request
5000-byte response
```

Amplification = 100x

# 27. IDS Detection (Snort Examples)

### Detect ICMP Flood

```snort
alert icmp any any -> $HOME_NET any \
(msg:"ICMP Flood"; sid:1000001;)
```

---

### Detect SYN Flood

```snort
alert tcp any any -> $HOME_NET 80 \
(flags:S; msg:"Possible SYN Flood"; sid:1000002;)
```
