# Information Security (InfoSec)

# What is Information?

## Information 

Information is:

* Processed, Organized and meaningful data
* Useful for decision making

Example:

```text id="vzlylu"
85, 90, 95  → Data
Average = 90% → Information
```

---

# What is Data?

## Data

Raw facts and figures without context.

Examples:

* Numbers
* Symbols
* Characters
* Images

Example:

```text id="yd3o3x"
101
Harsh
5000
```

---

# Difference Between Data and Information

| Data             | Information             |
| ---------------- | ----------------------- |
| Raw facts        | Processed data          |
| No meaning alone | Meaningful              |
| Unorganized      | Organized               |
| Input            | Output                  |
| Example: 85, 90  | Example: Average = 87.5 |

---

# What is Information Security (InfoSec)?

Information Security (InfoSec) is:

* Protecting information/data from

  * Unauthorized access
  * Modification
  * Disclosure
  * Destruction

whether information is:

* Digital
* Physical
* Verbal

---

# Simple Definition

```text id="qgn3vw"
InfoSec = Protection of meaningful information
```

---

# Relationship Between Information Security & Cybersecurity

| Information Security                 | Cybersecurity                         |
| ------------------------------------ | ------------------------------------- |
| Protects all forms of information    | Protects digital systems & cyberspace |
| Includes physical + digital security | Mainly digital security               |
| Broader concept                      | Subset of InfoSec                     |

---

# Important Concept

```text id="s94eyw"
Information in digital systems → Cybersecurity
```

OR

```text id="m9hq8m"
InfoSec protects information.
Cybersecurity protects information in cyberspace.
```

---

# CIA Triad (Core Principles of InfoSec)

| Principle       | Meaning                            |
| --------------- | ---------------------------------- |
| Confidentiality | Prevent unauthorized access        |
| Integrity       | Prevent unauthorized modification  |
| Availability    | Ensure data accessible when needed |

---

# Confidentiality

Protecting data from unauthorized users.

Examples:

* Passwords
* Encryption
* Access control

---

# Integrity

Ensuring data remains accurate and unchanged.

Examples:

* Hashing
* Digital signatures

---

# Availability

Ensuring systems/data available when needed.

Examples:

* Backups
* Redundancy
* Disaster recovery

---

A threat is:

* Any potential danger
* That can harm information or systems

# What is Cyber Warfare?

Cyber warfare is:

* Use of cyber attacks by nations/states
* Against another country’s:

  * Infrastructure
  * Networks
  * Military systems

Examples:

* Power grid attacks
* Government system attacks

---

# What is Information Warfare?

Information warfare is:

* Controlling/manipulating information
* To influence people or organizations

Examples:

* Fake news
* Psychological operations
* Propaganda campaigns

---

# Information Security Does NOT Deal With

| Not Directly Related                 | Reason                                |
| ------------------------------------ | ------------------------------------- |
| Physical warfare                     | Military combat not cyber-related     |
| Traditional crime without technology | Non-information attacks               |
| Civil engineering                    | Non-security engineering field        |
| Mechanical system design             | Not related to information protection |
| Pure hardware manufacturing          | Unless security-related               |
| Non-digital social disputes          | Outside security scope                |

# Important Interview Questions

### What is information?

Processed meaningful data.

### Difference between data and information?

Data is raw facts; information is processed meaningful data.

### What is InfoSec?

Protection of information from unauthorized access, modification, or destruction.

### What is CIA triad?

Confidentiality, Integrity, Availability.

### Difference between cybersecurity and information security?

Cybersecurity protects digital systems; InfoSec protects all information.
