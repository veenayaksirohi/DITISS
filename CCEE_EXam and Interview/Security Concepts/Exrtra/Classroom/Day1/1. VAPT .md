# VAPT (Vulnerability Assessment & Penetration Testing)

## What is VAPT?

VAPT stands for:

* **VA → Vulnerability Assessment**
* **PT → Penetration Testing**

It is a security testing process used to identify, analyze, and exploit security weaknesses in systems, networks, applications, and infrastructure.

---

# Difference Between VA and PT

| Feature    | Vulnerability Assessment | Penetration Testing       |
| ---------- | ------------------------ | ------------------------- |
| Purpose    | Find vulnerabilities     | Exploit vulnerabilities   |
| Approach   | Automated scanning       | Manual + automated attack |
| Output     | List of weaknesses       | Proof of exploitation     |
| Risk Level | Low                      | Higher                    |
| Focus      | Detection                | Exploitation              |
| Tools      | Nessus, OpenVAS          | Metasploit, Burp Suite    |

---

# 2. Scanning & Enumeration

# Interview Questions

## Basic

### What is VAPT?

Security assessment process combining vulnerability assessment and penetration testing.

### Difference between VA and PT?

VA identifies vulnerabilities; PT exploits them.

### What is OWASP?

Organization focused on web application security.

### What is CVE?

Public identifier for vulnerabilities.

### What is CVSS?

Vulnerability severity scoring system.

---

# Advanced Interview Questions

### What is privilege escalation?

Gaining higher-level access after compromise.

### Difference between active and passive reconnaissance?

Passive collects info without interaction; active directly interacts with target.

### What is lateral movement?

Moving across systems after initial compromise.

### What is pivoting?

Using compromised host to attack other systems.

### What is false positive?

Scanner reports vulnerability that doesn't actually exist.
