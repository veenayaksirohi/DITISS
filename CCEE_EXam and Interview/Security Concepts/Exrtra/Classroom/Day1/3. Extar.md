# Zero-Day Bug

# What is a Zero-Day Bug?

A **Zero-Day Bug/Vulnerability** is a security flaw:

* Unknown to the software vendor
* Unknown to defenders/security teams
* No official patch available

Attackers can exploit it before developers release a fix.

---

# Why Called “Zero-Day”?

Because:

* Developers had **0 days** to fix it before exploitation.

---

# Zero-Day Attack Lifecycle

```text id="on5mbx"
Vulnerability Discovered
        ↓
Exploit Developed
        ↓
Attack Launched
        ↓
Vendor Learns About Issue
        ↓
Patch Development
        ↓
Patch Release
```

---

# Components of Zero-Day

| Term                   | Meaning                     |
| ---------------------- | --------------------------- |
| Zero-Day Vulnerability | Unknown flaw                |
| Zero-Day Exploit       | Code exploiting flaw        |
| Zero-Day Attack        | Active attack using exploit |

---

# Characteristics of Zero-Day

* No patch available
* Difficult to detect
* High-value target
* Often used in APT attacks
* Can bypass antivirus/signatures

---

# Virtual Patching

Temporary protection without official patch.

Example:

* Blocking attack pattern in WAF/IPS

---

# Zero-Day vs N-Day

| Zero-Day        | N-Day            |
| --------------- | ---------------- |
| No patch exists | Patch exists     |
| Hard to detect  | Easier detection |
| More dangerous  | Less dangerous   |
