# Teams Involved in VAPT & Cybersecurity Operations

# 1. Red Team

## Purpose

Simulates real attackers.

## Responsibilities

* Exploitation
* Social engineering
* Privilege escalation
* Phishing simulations
* Advanced attack simulation

## Goal

Test organization’s detection and response capability.

## Skills Required

* Exploit development
* Web exploitation
* Networking
* Malware analysis
* OSINT

## Tools

* Metasploit
* Burp Suite
* Cobalt Strike

---

# 2. Blue Team

## Purpose

Defends systems from attacks.

## Responsibilities

* Monitoring
* Incident response
* Log analysis
* Threat detection
* Hardening systems

## Goal

Detect and stop attacks quickly.

## Activities

* SIEM monitoring
* Patch management
* Firewall management
* Threat hunting

## Tools

* Splunk
* Wireshark
* Snort

---

# 3. Purple Team

## Purpose

Collaboration between Red and Blue teams.

## Goal

Improve detection and defense mechanisms.

## Responsibilities

* Share attack techniques
* Improve SIEM alerts
* Validate detections
* Conduct attack simulations

---

# 4. White Team

## Purpose

Supervises and manages security exercises.

## Responsibilities

* Define rules of engagement
* Monitor activities
* Ensure compliance
* Coordinate communication

---

# 5. Yellow Team

## Purpose

Developers focused on secure coding.

## Responsibilities

* Secure SDLC
* Fix vulnerabilities
* Code review
* Secure architecture

---

### What is Red Teaming?

### Difference between Blue and Purple Team?

Blue defends; Purple coordinates Red and Blue collaboration.

### What does SOC do?

Monitors and responds to security incidents.

### What is threat hunting?

Proactively searching for hidden attackers.
