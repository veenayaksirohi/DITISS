| Terminology                    | Definition                                               | Example                                  | Key Point                              |
| ------------------------------ | -------------------------------------------------------- | ---------------------------------------- | -------------------------------------- |
| Vulnerability                  | Weakness in a system that can be exploited               | Weak password, unpatched software        | Weakness/opening in security           |
| Threat                         | Anything capable of causing harm                         | Malware, phishing, hacker                | Potential danger                       |
| Risk                           | Possibility of loss when a threat exploits vulnerability | Account compromise due to weak password  | Risk = Threat × Vulnerability × Impact |
| Asset                          | Anything valuable to organization                        | Data, servers, applications              | Needs protection                       |
| Bug                            | Error/flaw in software or hardware                       | Coding mistake, logic flaw               | Not all bugs are vulnerabilities       |
| Exploit                        | Method/code used to abuse vulnerability                  | SQL Injection exploit                    | Used to attack system                  |
| Zero-Day Exploit               | Exploit for unknown/unpatched vulnerability              | New browser vulnerability attack         | No fix/patch available                 |
| Information Security (InfoSec) | Protection of information in all forms                   | Data protection policies                 | Broader than cybersecurity             |
| Cybersecurity                  | Protection of cyberspace and digital systems             | Network security, endpoint security      | Focus on cyber threats                 |
| Lock Picking                   | Security bypass analogy                                  | Picking physical lock                    | Similar to bypassing authentication    |
| Vulnerability Assessment (VA)  | Identifying vulnerabilities                              | Scanning systems for weaknesses          | Usually non-exploitative               |
| Penetration Testing (PT)       | Simulated attack exploiting vulnerabilities              | Ethical hacking engagement               | Tests real-world impact                |
| VAPT                           | Combination of VA + PT                                   | Enterprise security testing              | Find + validate vulnerabilities        |
| Cyber Espionage                | Unauthorized digital spying                              | Stealing government secrets              | Intelligence gathering                 |
| Security Assessment            | Overall evaluation of security posture                   | Risk review, compliance check            | Broad security evaluation              |
| Security Audit                 | Formal examination of controls/policies                  | ISO 27001 audit                          | Compliance-focused                     |
| CIA Triad                      | Core principles of security                              | Confidentiality, Integrity, Availability | Foundation of security                 |
| Confidentiality                | Prevent unauthorized access                              | Encryption                               | Data secrecy                           |
| Integrity                      | Prevent unauthorized modification                        | Hash verification                        | Data accuracy                          |
| Availability                   | Ensure systems are accessible                            | Backup servers                           | System uptime                          |
| Non-Repudiation                | Prevent denial of actions                                | Digital signature                        | Proof of action                        |
| Authenticity                   | Verify genuineness of user/data                          | OTP, certificates                        | Identity verification                  |
| Hacking                        | Finding/exploiting system weaknesses                     | Penetration testing, exploit development | No universal definition                |
| Malware                        | Malicious software designed to harm                      | Virus, ransomware                        | Common cyber threat                    |
| Phishing                       | Fake communication to steal info                         | Fake banking email                       | Social engineering attack              |
| Insider Threat                 | Threat from authorized user                              | Employee data theft                      | Internal risk                          |
| Misconfiguration               | Incorrect security settings                              | Open database port                       | Common vulnerability                   |
| Patch                          | Software update fixing issues                            | Windows security update                  | Removes vulnerabilities                |
| Attack Surface                 | Total exposed points attackers can target                | Open ports, APIs                         | Larger surface = higher risk           |
| Payload                        | Actual malicious code delivered in attack                | Reverse shell payload                    | Executes attacker objective            |
| Backdoor                       | Hidden unauthorized access mechanism                     | Secret admin account                     | Bypasses authentication                |
| Authentication                 | Verifying identity                                       | Password login                           | “Who are you?”                         |
| Authorization                  | Granting permissions                                     | Admin access rights                      | “What can you do?”                     |
| Encryption                     | Converting data into unreadable form                     | AES encrypted files                      | Protects confidentiality               |
| Decryption                     | Converting encrypted data back                           | Reading encrypted message                | Reverse of encryption                  |
| Hashing                        | One-way data transformation                              | SHA-256 hash                             | Integrity verification                 |
| Digital Signature              | Electronic proof of sender authenticity                  | Signed PDF                               | Integrity + non-repudiation            |
| Firewall                       | Filters network traffic                                  | Blocking unauthorized ports              | Network protection                     |
| IDS                            | Detects suspicious activity                              | Snort alerts                             | Intrusion detection                    |
| IPS                            | Detects and blocks attacks                               | Blocking malicious traffic               | Intrusion prevention                   |
| Social Engineering             | Manipulating people for access                           | Fake support call                        | Human-based attack                     |
| Brute Force Attack             | Trying many password combinations                        | Password guessing                        | Authentication attack                  |
| Ransomware                     | Malware encrypting files for ransom                      | WannaCry                                 | Availability attack                    |
| Botnet                         | Group of compromised systems                             | DDoS attack network                      | Remotely controlled devices            |
| DDoS                           | Flooding target with traffic                             | Website outage                           | Availability attack                    |
| SQL Injection                  | Injecting SQL queries into app                           | `' OR 1=1 --`                            | Database attack                        |
| XSS                            | Injecting malicious scripts in webpage                   | JavaScript alert payload                 | Client-side attack                     |
| CSRF                           | Forcing authenticated user actions                       | Unauthorized fund transfer               | Session-based attack                   |
| Session Hijacking              | Taking over user session                                 | Stolen session cookie                    | Identity theft                         |
| Rootkit                        | Malware hiding attacker presence                         | Hidden kernel module                     | Stealth malware                        |
| Trojan                         | Malware disguised as legitimate software                 | Fake software installer                  | User-tricked malware                   |
| Worm                           | Self-replicating malware                                 | Network spreading worm                   | Spreads automatically                  |
| Virus                          | Malware attaching to files                               | Infected executable                      | Needs host file                        |
| Spyware                        | Malware secretly collecting data                         | Keylogger                                | Monitoring malware                     |
| Keylogger                      | Records keystrokes                                       | Password theft tool                      | Credential stealing                    |
| Honeypot                       | Decoy system to attract attackers                        | Fake vulnerable server                   | Attack analysis                        |
| Red Team                       | Simulates real attackers                                 | Adversary emulation                      | Offensive security                     |
| Blue Team                      | Defends systems                                          | SOC analysts                             | Defensive security                     |
| SOC                            | Security Operations Center                               | Monitoring alerts                        | Central security team                  |
| SIEM                           | Collects/analyzes security logs                          | Splunk, QRadar                           | Threat monitoring                      |
| Incident Response              | Handling security incidents                              | Malware containment                      | Minimize damage                        |
| Compliance                     | Following standards/regulations                          | GDPR, PCI-DSS                            | Legal/security requirement             |
| Cyber Forensics                | Investigating cyber incidents                            | Disk analysis                            | Digital evidence collection            |
