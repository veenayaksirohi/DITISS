# Injection and Inclusion Attacks Notes

## Introduction

Injection and Inclusion attacks are among the most dangerous web application vulnerabilities. They occur when attackers send malicious input to an application, causing unintended execution of commands, code, files, or queries.

These attacks are part of the OWASP Top vulnerabilities.

---

# 1. Injection Attacks

## Definition

Injection occurs when untrusted user input is interpreted as commands or queries by an interpreter.

## Common Targets

* Databases
* Operating systems
* LDAP services
* XML parsers
* Application interpreters

---

# Types of Injection Attacks

| Type              | Target           |
| ----------------- | ---------------- |
| SQL Injection     | Database         |
| Command Injection | Operating System |
| LDAP Injection    | LDAP Directory   |
| XML Injection     | XML Parser       |
| XPath Injection   | XML Query        |
| NoSQL Injection   | NoSQL Database   |
| Code Injection    | Application Code |

---

# SQL Injection (SQLi)

## Definition

An attacker inserts malicious SQL code into application queries.

---

## How SQL Injection Works

### Normal Query

```sql
SELECT * FROM users 
WHERE username='admin' 
AND password='1234';
```

### Malicious Input

```sql
' OR '1'='1
```

### Modified Query

```sql
SELECT * FROM users 
WHERE username='' OR '1'='1'
AND password='';
```

Result → Authentication bypass.

---

## SQL Injection Flow

---

## Types of SQL Injection

### 1. In-Band SQLi

Attacker receives results directly.

#### Types

* Error-based SQLi
* Union-based SQLi

---

### 2. Blind SQLi

No direct output visible.

#### Types

* Boolean-based
* Time-based

---

### 3. Out-of-Band SQLi

Uses another communication channel.

---

# SQL Injection Examples

## Authentication Bypass

```sql
' OR 1=1 --
```

---

## Database Enumeration

```sql
UNION SELECT table_name,NULL 
FROM information_schema.tables;
```

---

## Data Extraction

```sql
UNION SELECT username,password FROM users;
```

---

# Impact of SQL Injection

| Impact                 | Description                 |
| ---------------------- | --------------------------- |
| Data Theft             | Steal sensitive information |
| Authentication Bypass  | Login without password      |
| Database Deletion      | Delete records              |
| Remote Execution       | Execute commands            |
| Full System Compromise | Gain server access          |

---

# Prevention of SQL Injection

## 1. Prepared Statements

### Unsafe

```php
$query = "SELECT * FROM users WHERE id='$id'";
```

### Safe

```php
$stmt = $conn->prepare(
"SELECT * FROM users WHERE id=?");
```

---

## 2. Parameterized Queries

Separates code and data.

---

## 3. Input Validation

* Reject special characters
* Validate type and length

---

## 4. Least Privilege

Database accounts should have minimal permissions.

---

## 5. Web Application Firewall (WAF)

Filters malicious traffic.

---

# Command Injection

## Definition

Attacker executes operating system commands through vulnerable applications.

---

## Command Injection Process

---

## Example

### Vulnerable Code

```php
system("ping " . $_GET['ip']);
```

### Malicious Input

```bash
127.0.0.1 && whoami
```

### Executed Command

```bash
ping 127.0.0.1 && whoami
```

---

# Effects of Command Injection

* Server compromise
* File deletion
* Malware installation
* Privilege escalation

---

# Prevention

* Avoid system() calls
* Input sanitization
* Allowlist validation
* Use safe APIs

---

# LDAP Injection

## Definition

Manipulating LDAP queries using malicious input.

---

## Example

### Vulnerable LDAP Query

```text
(uid=" + user + ")(password=" + pass + ")
```

### Malicious Input

```text
*)(|(uid=*))
```

---

# Prevention

* Parameterized LDAP queries
* Input validation
* Escape special characters

---

# Prevention of File Inclusion

## Input Validation

Allow only expected filenames.

---

## Allowlist Approach

```php
$allowed = ["home.php","about.php"];
```

---

## Disable Remote Inclusion

In PHP:

```ini
allow_url_include = Off
```

---

## Secure File Paths

Avoid dynamic file inclusion.

---

# Difference Between LFI and RFI

| Feature           | LFI              | RFI                 |
| ----------------- | ---------------- | ------------------- |
| File Source       | Local server     | Remote server       |
| Internet Required | No               | Yes                 |
| Severity          | High             | Very High           |
| Main Goal         | Read local files | Execute remote code |

---

# Injection vs Inclusion

| Injection               | Inclusion             |
| ----------------------- | --------------------- |
| Inject commands/queries | Include files         |
| Targets interpreters    | Targets file systems  |
| SQLi is common          | LFI/RFI common        |
| Manipulates execution   | Loads malicious files |

---

# Common Special Characters Used

| Character | Purpose                   |
| --------- | ------------------------- |
| '         | Break SQL query           |
| --        | SQL comment               |
| ;         | Command separator         |
| &&        | Execute multiple commands |
| ../       | Directory traversal       |
| |         | Pipe output               |
