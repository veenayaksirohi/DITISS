## 1. Cryptography

### Definition

Cryptography is a Science of Securing information by converting readable data (plaintext) into unreadable data (ciphertext) to protect CIA + AA

## Types of Cryptography

### 1. Symmetric Key Cryptography

Same key is used for encryption and decryption.

```
Plaintext
    ↓
Encryption (Key K)
    ↓
Ciphertext
    ↓
Decryption (Key K)
    ↓
Plaintext
```

### Examples

* DES
* 3DES
* AES
* Blowfish

### Advantages

* Fast
* Efficient for large data

### Disadvantages

* Key distribution problem
* Less scalable

---

### 2. Asymmetric Key Cryptography

Uses two keys.

* Public Key → Encrypt
* Private Key → Decrypt

```
Public Key  → Encryption
Private Key → Decryption
```

### Examples

* RSA
* ECC
* ElGamal

### Advantages

* Secure key exchange
* Supports Digital Signatures

### Disadvantages

* Slower than symmetric encryption

---

## Symmetric vs Asymmetric

| Feature  | Symmetric            | Asymmetric   |
| -------- | -------------------- | ------------ |
| Keys     | One                  | Two          |
| Speed    | Fast                 | Slow         |
| Security | Lower                | Higher       |
| Example  | AES                  | RSA          |
| Usage    | Bulk Data Encryption | Key Exchange |


In **Classical Cryptography**, encryption techniques are mainly divided into two categories:

| Category                 | Meaning                                                             | Example                                                                |
| ------------------------ | ------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Substitution Cipher**  | Characters are replaced with other characters, numbers, or symbols. | Caesar Cipher, Monoalphabetic Cipher, Vigenère Cipher, Playfair Cipher |
| **Transposition Cipher** | Characters remain the same, but their positions are rearranged.     | Rail Fence Cipher, Columnar Transposition Cipher                       |

---

# 1. Substitution Cipher

### Definition

A cipher in which each plaintext character is substituted (replaced) with another character according to a rule.

### Example

Plaintext:

```
HELLO
```

Using Caesar Cipher (Shift +3):

```
H → K
E → H
L → O
L → O
O → R
```

Ciphertext:

```
KHOOR
```

### Characteristics

* Letters are changed.
* Position remains the same.
* Easy to understand.
* Vulnerable to frequency analysis.

### Types of Substitution Ciphers

| Cipher                | Description                     |
| --------------------- | ------------------------------- |
| Caesar Cipher         | Shift letters by fixed value    |
| Monoalphabetic Cipher | One fixed substitution alphabet |
| Polyalphabetic Cipher | Multiple substitution alphabets |
| Vigenère Cipher       | Uses keyword-based shifting     |
| Playfair Cipher       | Encrypts pairs of letters       |
| Hill Cipher           | Uses matrix operations          |

---

# 2. Transposition Cipher

### Definition

A cipher in which the positions of plaintext characters are rearranged without changing the actual characters.

### Example

Plaintext:

```
HELLO
```

Rearrange positions:

```
H E L L O
↓ ↓ ↓ ↓ ↓
L O H E L
```

Ciphertext:

```
LOHEL
```

### Characteristics

* Letters remain unchanged.
* Positions are changed.
* Harder to detect visually.
* Often combined with substitution for stronger security.

### Types of Transposition Ciphers

| Cipher                 | Description                       |
| ---------------------- | --------------------------------- |
| Rail Fence Cipher      | Zig-zag arrangement of letters    |
| Columnar Transposition | Write in rows and read by columns |
| Double Transposition   | Apply transposition twice         |

# Comparison

| Feature                     | Substitution Cipher | Transposition Cipher |
| --------------------------- | ------------------- | -------------------- |
| Changes letters?            | Yes                 | No                   |
| Changes positions?          | No                  | Yes                  |
| Preserves letter frequency? | Yes                 | Yes                  |
| Example                     | Caesar, Vigenère    | Rail Fence, Columnar |
| Security                    | Moderate            | Moderate             |
| Main Idea                   | Replace symbols     | Rearrange symbols    |

### Simple Memory Trick

* **Substitution = Replace Characters**

  ```
  A → D
  B → E
  C → F
  ```

* **Transposition = Shuffle Characters**

  ```
  ABCDEF → CDEFAB
  ```
