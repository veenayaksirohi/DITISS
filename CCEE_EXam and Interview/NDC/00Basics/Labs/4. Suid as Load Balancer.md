# Configure Squid as a Reverse Proxy Load Balancer (Round Robin)

## Lab Setup

| Machine | IP Address          | Purpose                             |
| ------- | ------------------- | ----------------------------------- |
| Deb1    | **192.168.229.141** | Squid Reverse Proxy / Load Balancer |
| Deb2    | **192.168.229.100** | Backend Web Server                  |
| Deb3    | **192.168.229.144** | Backend Web Server                  |
| Client  | Any                 | Accesses Squid                      |

### Architecture

```
                  Client
                     |
                     |
             192.168.229.141
          +-------------------+
          |   Squid Proxy     |
          |  Reverse Proxy    |
          | Load Balancer     |
          +-------------------+
             |             |
             |             |
             |             |
    192.168.229.100   192.168.229.144
      Apache/Nginx      Apache/Nginx
```
# 1. Change the listening port

http_port 80 accel vhost defaultsite=192.168.229.141

# 2. HTTP Access

**Under**:
# INSERT YOUR OWN RULE(S) HERE TO ALLOW ACCESS FROM YOUR CLIENTS

http_access allow all

# Keep the existing:
http_access deny all

# 3. CACHE PEER OPTIONS

cache_peer 192.168.229.100 parent 80 0 no-query originserver round-robin weight=1 name=deb2

cache_peer 192.168.229.144 parent 80 0 no-query originserver round-robin weight=1 name=deb3

# 4. CACHE PEER ACCESS

cache_peer_access deb2 allow all
cache_peer_access deb2 deny all

cache_peer_access deb3 allow all
cache_peer_access deb3 deny all

# 5. Disable Caching

# Add before the first refresh_pattern line

cache deny all
