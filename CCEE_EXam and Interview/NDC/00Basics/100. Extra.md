## Hashing

### Definition

Converts data into a fixed-length value called Hash Digest.

```
Message
   ↓
Hash Function
   ↓
Hash Value
```

### Characteristics

* One-way process
* Cannot be reversed
* Same input → Same output
* Small change → Completely different hash

### Examples

* MD5
* SHA-1
* SHA-256
* SHA-512

### Uses

* Password Storage
* Integrity Checking
* Digital Signatures

---

## AES vs SHA

| Feature      | AES             | SHA       |
| ------------ | --------------- | --------- |
| Type         | Encryption      | Hashing   |
| Reversible   | Yes             | No        |
| Purpose      | Confidentiality | Integrity |
| Key Required | Yes             | No        |

## Digital Signature

### Purpose

Provides:

* Authentication
* Integrity
* Non-Repudiation

### Working

1. Sender creates hash of message.
2. Hash encrypted using sender's private key.
3. Signature attached to message.
4. Receiver verifies using sender's public key.

```
Message
   ↓
Hash
   ↓
Encrypt with Private Key
   ↓
Digital Signature
```

---

## Diffie-Hellman Key Exchange

### Purpose

Securely exchange keys over an insecure network.

### Process

```
Alice -------- Internet -------- Bob

Generate Public Values
      ↓
Exchange Public Values
      ↓
Generate Same Secret Key
```

### Benefit

Even if attacker sees exchanged values, secret key cannot be calculated easily.

# PKI (Public Key Infrastructure)

## Definition

PKI is a framework of hardware, software, policies, and procedures used to manage digital certificates and public-key encryption.

It establishes trust between users, systems, and organizations.

---

## Components of PKI

### 1. Certificate Authority (CA)

Trusted organization that issues digital certificates.

Examples:

* DigiCert
* Let's Encrypt

### Functions

* Issues certificates
* Verifies identity
* Revokes certificates

---

### 2. Registration Authority (RA)

Acts on behalf of CA.

Functions:

* Verifies user identity
* Sends request to CA

---

### 3. Digital Certificate

Electronic identity card.

Contains:

* Owner Name
* Public Key
* CA Name
* Expiry Date
* Serial Number
* Digital Signature

---

### 4. Public Key

Shared openly for encryption and verification.

---

### 5. Private Key

Secret key owned by user.

Used for:

* Decryption
* Signing

---

# 5-Mark Exam Answer

### What is PKI?

Public Key Infrastructure (PKI) is a framework that uses public-key cryptography, digital certificates, Certificate Authorities (CA), and Registration Authorities (RA) to provide secure communication, authentication, integrity, and non-repudiation over a network. PKI enables trusted exchange of information and is widely used in HTTPS, digital signatures, VPNs, and secure email systems.

### What is Cryptography?

Cryptography is the process of securing information by converting plaintext into ciphertext using encryption algorithms and keys. It ensures confidentiality, integrity, authentication, and non-repudiation. Major techniques include symmetric encryption (AES), asymmetric encryption (RSA), hashing (SHA-256), and digital signatures.
