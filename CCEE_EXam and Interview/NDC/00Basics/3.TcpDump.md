# TCPDUMP Notes

## What is TCPDUMP?

**tcpdump** is a command-line packet analyzer used to **capture and analyze network traffic** in Linux/Unix systems.

* Similar to Wireshark, but runs in terminal.
* Uses **libpcap** library.
* Captures packets flowing through a network interface.
* Commonly used by Network Engineers, System Administrators, and Security Analysts.

---

## Basic Syntax

```bash
tcpdump [options] [filter]
```

---

## Check Available Interfaces

```bash
tcpdump -D
```

Example Output:

```bash
1.eth0
2.lo
3.wlan0
```

---

## Capture Packets on All Interfaces

```bash
tcpdump -i any
```

---

## Capture Packets on Specific Interface

```bash
tcpdump -i eth0
```

---

## Disable Name Resolution

Shows IP addresses instead of hostnames.

```bash
tcpdump -n
```

Example:

```bash
tcpdump -i eth0 -n
```

---

## Capture Specific Number of Packets

```bash
tcpdump -c 10
```

Capture only 10 packets.

---

## Save Capture to File

```bash
tcpdump -i eth0 -w capture.pcap
```

Output file can be opened in Wireshark.

---

## Read Existing PCAP File

```bash
tcpdump -r capture.pcap
```

---

## Show Packet Details

```bash
tcpdump -v
```

More details:

```bash
tcpdump -vv
```

Maximum details:

```bash
tcpdump -vvv
```

---

# Common Filters

## Capture Traffic from Specific Host

```bash
tcpdump host 192.168.1.10
```

---

## Source Host

```bash
tcpdump src host 192.168.1.10
```

---

## Destination Host

```bash
tcpdump dst host 192.168.1.10
```

---

## Specific Port

```bash
tcpdump port 80
```

---

## Source Port

```bash
tcpdump src port 80
```

---

## Destination Port

```bash
tcpdump dst port 443
```

---

## Multiple Ports

```bash
tcpdump port 80 or port 443
```

---

## TCP Traffic

```bash
tcpdump tcp
```

---

## UDP Traffic

```bash
tcpdump udp
```

---

## ICMP Traffic (Ping)

```bash
tcpdump icmp
```

---

# Advanced Filters

## Capture HTTP Traffic

```bash
tcpdump tcp port 80
```

---

## Capture HTTPS Traffic

```bash
tcpdump tcp port 443
```

---

## Capture SSH Traffic

```bash
tcpdump port 22
```

---

## Capture DNS Traffic

```bash
tcpdump port 53
```

---

## Capture Traffic Between Two Hosts

```bash
tcpdump host 192.168.1.10 and host 192.168.1.20
```

---

## Exclude Traffic

```bash
tcpdump not port 22
```

---

## Combine Filters

```bash
tcpdump tcp and port 80
```

```bash
tcpdump host 192.168.1.10 and port 443
```

# TCPDUMP vs Wireshark

| Feature         | TCPDUMP   | Wireshark |
| --------------- | --------- | --------- |
| Interface       | CLI       | GUI       |
| Resource Usage  | Low       | Higher    |
| Remote Servers  | Excellent | Limited   |
| Packet Capture  | Yes       | Yes       |
| Packet Analysis | Basic     | Advanced  |
| Automation      | Easy      | Difficult |

# Interview Questions

### 1. What is tcpdump?

A command-line packet capture and network troubleshooting tool.

### 2. Which library does tcpdump use?

**libpcap**

### 3. How do you capture packets on interface eth0?

```bash
tcpdump -i eth0
```

### 4. How do you save packets to a file?

```bash
tcpdump -w file.pcap
```

### 5. How do you read a pcap file?

```bash
tcpdump -r file.pcap
```

### 6. Difference between tcpdump and Wireshark?

* tcpdump = CLI-based
* Wireshark = GUI-based

### 7. How do you capture only ICMP packets?

```bash
tcpdump icmp
```

### 8. How do you capture only DNS traffic?

```bash
tcpdump port 53
```

### 9. How do you capture traffic from a specific host?

```bash
tcpdump host <IP>
```

### 10. What is a PCAP file?

A file format used to store captured network packets for later analysis.
