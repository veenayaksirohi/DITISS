# Wireshark Working Explained

## What is Wireshark?

Wireshark is a **network packet analyzer** used to capture and inspect network traffic in real time.

It helps network administrators, security analysts, and students understand:

* What data is flowing through the network
* Which devices are communicating
* Which protocols are being used
* Network errors and security issues

---

# How Wireshark Works

## Step 1: Packet Capture

Wireshark captures packets from a network interface card (NIC).

Example Interfaces:

* Ethernet Adapter
* Wi-Fi Adapter
* Virtual Network Adapter

When data travels across the network, the NIC receives packets and Wireshark captures copies of them.

```
Device A ---> Switch ---> Device B
                 |
             Wireshark
```

---

## Step 2: Promiscuous Mode

Normally a NIC only accepts packets addressed to it.

In **Promiscuous Mode**, the NIC captures:

* Incoming packets
* Outgoing packets
* Broadcast packets
* Sometimes packets for other devices (depending on network topology)

This allows Wireshark to see more network traffic.

---

## Step 3: Packet Decoding

Raw packets are difficult to read.

Wireshark decodes them into protocols such as:

* Ethernet
* ARP
* IP
* ICMP
* TCP
* UDP
* DNS
* HTTP
* HTTPS
* FTP
* SSH

Example:

```
Ethernet
  ↓
IP
  ↓
TCP
  ↓
HTTP
```

This is called **Protocol Stack Analysis**.

---

## Step 4: Displaying Packets

Wireshark displays captured packets in three sections.

### Packet List Pane

Shows all packets.

```
No  Time      Source      Destination  Protocol
1   0.0001    192.168.1.5 8.8.8.8      DNS
2   0.0012    8.8.8.8     192.168.1.5  DNS
```

---

### Packet Details Pane

Shows protocol information.

```
Frame
Ethernet II
Internet Protocol Version 4
Transmission Control Protocol
HTTP
```

---

### Packet Bytes Pane

Shows packet data in hexadecimal.

```
45 00 00 3c 1c 46 40 00
40 06 b1 e6 c0 a8 01 05
```

# Packet Flow Example

Suppose you open Google.

### DNS Query

```
PC -> DNS Server
"What is google.com?"
```

---

### DNS Reply

```
DNS Server -> PC
google.com = 142.x.x.x
```

---

### TCP Handshake

```
Client -> SYN
Server -> SYN-ACK
Client -> ACK
```

Connection established.

---

### HTTP/HTTPS Request

```
GET /
Host: google.com
```

---

### Server Response

```
200 OK
HTML Data
```

All these packets can be viewed in Wireshark.

# Interview Questions

### 1. What is Wireshark?

A network protocol analyzer used to capture and analyze packets.

### 2. What is a packet?

A small unit of data transmitted over a network.

### 3. What is promiscuous mode?

Mode in which a NIC captures all packets it can see.

### 4. What is packet capture?

The process of collecting network packets for analysis.

### 5. Which protocols can Wireshark analyze?

TCP, UDP, IP, ICMP, ARP, DNS, HTTP, HTTPS, FTP, SSH, etc.

### 6. Can Wireshark decrypt HTTPS traffic?

Not normally. It can only see encrypted data unless SSL/TLS keys are provided.

### 7. Difference between Capture Filter and Display Filter?

| Capture Filter              | Display Filter                    |
| --------------------------- | --------------------------------- |
| Applied before capture      | Applied after capture             |
| Reduces captured packets    | Filters displayed packets         |
| Example: `host 192.168.1.1` | Example: `ip.addr == 192.168.1.1` |

### 8. What is a pcap file?

A packet capture file used to store network traffic.

### 9. What is the TCP Three-Way Handshake?

SYN → SYN-ACK → ACK

### 10. What are the three panes in Wireshark?

Packet List, Packet Details, Packet Bytes.

# Wireshark Filter Cheat Sheet

| Purpose                    | Filter |
| -------------------------- | ------ |
| Show all TCP packets       | `tcp`  |
| Show all UDP packets       | `udp`  |
| Show all ICMP packets      | `icmp` |
| Show all ARP packets       | `arp`  |
| Show all DNS packets       | `dns`  |
| Show all HTTP packets      | `http` |
| Show all HTTPS/TLS packets | `tls`  |
| Show all FTP packets       | `ftp`  |
| Show all SSH packets       | `ssh`  |
| Show all DHCP packets      | `dhcp` |
| Show all SMTP packets      | `smtp` |
| Show all SNMP packets      | `snmp` |

---

## IP Address Filters

| Purpose          | Filter                      |
| ---------------- | --------------------------- |
| Specific IP      | `ip.addr == 192.168.1.10`   |
| Source IP        | `ip.src == 192.168.1.10`    |
| Destination IP   | `ip.dst == 192.168.1.10`    |
| IPv6 Traffic     | `ipv6`                      |
| Specific Network | `ip.addr == 192.168.1.0/24` |

---

## Port Filters

| Purpose             | Filter              |
| ------------------- | ------------------- |
| Port 80             | `tcp.port == 80`    |
| Source Port 80      | `tcp.srcport == 80` |
| Destination Port 80 | `tcp.dstport == 80` |
| Port 443            | `tcp.port == 443`   |
| Port 22 (SSH)       | `tcp.port == 22`    |
| Port 21 (FTP)       | `tcp.port == 21`    |
| DNS Port            | `udp.port == 53`    |

---

## TCP Analysis Filters

| Purpose         | Filter                        |
| --------------- | ----------------------------- |
| SYN Packets     | `tcp.flags.syn == 1`          |
| ACK Packets     | `tcp.flags.ack == 1`          |
| FIN Packets     | `tcp.flags.fin == 1`          |
| RST Packets     | `tcp.flags.reset == 1`        |
| Retransmissions | `tcp.analysis.retransmission` |
| Duplicate ACK   | `tcp.analysis.duplicate_ack`  |
| Lost Segments   | `tcp.analysis.lost_segment`   |

---

## HTTP Filters

| Purpose           | Filter                          |
| ----------------- | ------------------------------- |
| GET Requests      | `http.request.method == "GET"`  |
| POST Requests     | `http.request.method == "POST"` |
| Response Code 200 | `http.response.code == 200`     |
| Response Code 404 | `http.response.code == 404`     |
| Host Name         | `http.host == "example.com"`    |

---

## DNS Filters

| Purpose       | Filter                         |
| ------------- | ------------------------------ |
| DNS Queries   | `dns.flags.response == 0`      |
| DNS Responses | `dns.flags.response == 1`      |
| Query Name    | `dns.qry.name == "google.com"` |
| DNS Errors    | `dns.flags.rcode != 0`         |

---

## Useful Combined Filters

| Purpose              | Filter                                      |   |       |
| -------------------- | ------------------------------------------- | - | ----- |
| TCP from specific IP | `tcp && ip.addr == 192.168.1.10`            |   |       |
| HTTP from IP         | `http && ip.src == 192.168.1.10`            |   |       |
| DNS and ICMP         | `dns                                        |   | icmp` |
| Exclude DNS          | `!dns`                                      |   |       |
| Exclude ARP          | `!arp`                                      |   |       |
| TCP Port 80 from IP  | `tcp.port == 80 && ip.addr == 192.168.1.10` |   |       |

---

## Capture Filters (Before Capture Starts)

| Purpose                  | Filter                  |
| ------------------------ | ----------------------- |
| Capture all TCP          | `tcp`                   |
| Capture all UDP          | `udp`                   |
| Capture host             | `host 192.168.1.10`     |
| Capture source host      | `src host 192.168.1.10` |
| Capture destination host | `dst host 192.168.1.10` |
| Capture port 80          | `port 80`               |
| Capture DNS              | `port 53`               |
| Capture subnet           | `net 192.168.1.0/24`    |
