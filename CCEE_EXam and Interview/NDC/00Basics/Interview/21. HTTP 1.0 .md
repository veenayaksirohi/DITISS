## HTTP/1.0 or Non-persistent Connection 
**HTTP/1.0** is the first widely used version of HTTP, introduced in **1996**. It defines how a web browser (client) communicates with a web server to request and receive web pages.

### Working

```text
Client (Browser)                 Server
      |------ HTTP Request ------>|
      |<----- HTTP Response ------|
```

### Features

* One request per TCP connection.
* Connection is **closed after each request/response** (non-persistent connection).
* Supports methods like **GET, POST, HEAD**.
* Supports HTTP status codes (200, 404, etc.).
* Headers are included in requests and responses.

### Request Format

```http
GET /index.html HTTP/1.0
Host: www.example.com

```

### Response Format

```http
HTTP/1.0 200 OK
Content-Type: text/html
Content-Length: 1256

<html>
...
</html>
```

### Advantages

* Simple and easy to implement.
* Suitable for small websites.

### Disadvantages

* **Non-persistent connections:** A new TCP connection is required for every file (HTML, CSS, JS, images).
* Higher latency and slower page loading.
* No mandatory `Host` header (virtual hosting is difficult).
* No chunked transfer encoding.

### Example

If a webpage contains:

* 1 HTML file
* 2 CSS files
* 3 Images

**HTTP/1.0** opens **6 separate TCP connections**, one for each resource.



### HTTP/1.0 vs HTTP/1.1

| Feature          | HTTP/1.0                 | HTTP/1.1                            |
| ---------------- | ------------------------ | ----------------------------------- |
| Connection       | Non-persistent (default) | Persistent (Keep-Alive by default)  |
| TCP Connections  | One per request          | Multiple requests on one connection |
| Host Header      | Optional                 | Mandatory                           |
| Performance      | Slower                   | Faster                              |
| Caching          | Basic                    | Improved                            |
| Chunked Transfer | No                       | Yes                                 |

### 2-Mark Exam Answer

> **HTTP/1.0** is the first widely used version of the HyperText Transfer Protocol. It uses **non-persistent TCP connections**, meaning a new connection is established for every HTTP request and closed after the response. It supports methods like **GET, POST, and HEAD**, but is slower than HTTP/1.1 because multiple resources require multiple TCP connections.
