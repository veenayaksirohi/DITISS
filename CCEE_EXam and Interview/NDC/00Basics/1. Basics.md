# Network Defense and Countermeasures – Detailed Notes

# 1. Introduction to Network Defense

## What is Network Defense?

Network Defense is the practice of protecting computer networks from unauthorized access, misuse, attacks, modification, destruction, or disclosure of data.

### Goals of Network Defense

1. Confidentiality – Prevent unauthorized access to data.
2. Integrity – Ensure data is not altered.
3. Availability – Ensure systems remain accessible.
4. Authentication – Verify user identities.
5. Authorization – Control access rights.
6. Accountability – Track user actions.

---

# 2. Network Security Concepts

## What is Network Security?

Network Security is the process of protecting network infrastructure and data from cyber threats.

### Importance

* Protects sensitive information
* Prevents cyber attacks
* Ensures business continuity
* Maintains customer trust
* Meets compliance requirements

---

## CIA Triad

### 1. Confidentiality

Ensures only authorized users can access information.

Examples:

* Encryption
* VPN
* Access Control

### 2. Integrity

Ensures data remains accurate and unchanged.

Examples:

* Hashing
* Digital Signatures
* Checksums

### 3. Availability

Ensures systems are available when needed.

Examples:

* Load Balancing
* Redundancy
* Backup Systems

---

## Types of Network Attacks

### 1. Passive Attacks

Attacker only monitors network traffic.

Examples:

* Packet Sniffing
* Eavesdropping
* Traffic Analysis

Characteristics:

* Difficult to detect
* No modification of data

---

### 2. Active Attacks

Attacker modifies or disrupts communications.

Examples:

* DoS Attack
* DDoS Attack
* Man-in-the-Middle
* Spoofing

Characteristics:

* Easier to detect
* Causes direct damage

---

## Common Network Threats

### Malware

Malicious software designed to damage systems.

Types:

* Virus
* Worm
* Trojan Horse
* Spyware
* Adware
* Ransomware

---

### Phishing

Fraudulent attempts to steal sensitive information through emails or fake websites.

Examples:

* Email Phishing
* Spear Phishing
* Whaling

---

### Spoofing

Pretending to be another entity.

Types:

* IP Spoofing
* MAC Spoofing
* DNS Spoofing
* Email Spoofing

---

### Denial of Service (DoS)

Makes a system unavailable by flooding it with traffic.

#### DDoS (Distributed DoS)

Attack launched from multiple compromised systems.

Examples:

* SYN Flood
* UDP Flood
* ICMP Flood

---

## Security Controls

### Administrative Controls

Policies and procedures.

Examples:

* Security Policies
* Employee Training
* Incident Response Plans

---

### Technical Controls

Technology-based protections.

Examples:

* Firewall
* IDS
* IPS
* Antivirus

---

### Physical Controls

Protect physical access.

Examples:

* Locks
* Security Guards
* CCTV Cameras

---

# 3. Firewalls

## What is a Firewall?

A Firewall is a security device or software that monitors and controls incoming and outgoing network traffic based on predefined security rules.

### Main Purpose

Act as a barrier between:

Trusted Network ↔ Untrusted Network

Example:

```
Internet
    |
 Firewall
    |
Internal Network
```

---

## Functions of Firewall

* Traffic Filtering
* Access Control
* Logging
* Monitoring
* NAT (Network Address Translation)
* VPN Support

---

## Types of Firewalls

### 1. Packet Filtering Firewall

Works at Layer 3 and Layer 4.

Checks:

* Source IP
* Destination IP
* Port Number
* Protocol

Advantages:

* Fast
* Low resource usage

Disadvantages:

* No payload inspection

---

### 2. Stateful Inspection Firewall

Tracks active connections.

Checks:

* Packet information
* Connection state

Advantages:

* More secure than packet filtering

Disadvantages:

* More resource intensive

---

### 3. Circuit-Level Gateway

Operates at Session Layer.

Checks:

* TCP Handshakes
* Session Establishment

Advantages:

* Hides internal network

Disadvantages:

* Does not inspect payload

---

### 4. Application-Level Firewall (Proxy Firewall)

Works at Application Layer.

Inspects:

* HTTP
* FTP
* SMTP
* DNS

Advantages:

* Deep Inspection

Disadvantages:

* Slower performance

---

### 5. Next Generation Firewall (NGFW)

Modern firewall with advanced security.

Features:

* Deep Packet Inspection (DPI)
* IDS/IPS
* Application Awareness
* Malware Protection
* User Identity Management

Examples:

* Palo Alto Networks Firewalls
* Fortinet FortiGate
* Cisco Firepower

---

## Firewall Deployment Types

### Network Firewall

Protects entire network.

```
Internet
   |
Firewall
   |
LAN
```

---

### Host-Based Firewall

Installed on individual systems.

Examples:

* Windows Defender Firewall
* iptables

---

## Firewall Rules Example

Allow HTTP:

```
ALLOW TCP ANY -> 192.168.1.10 PORT 80
```

Allow HTTPS:

```
ALLOW TCP ANY -> 192.168.1.10 PORT 443
```

Block Telnet:

```
DENY TCP ANY -> ANY PORT 23
```

# 4. IDS (Intrusion Detection System)

## What is IDS?

An Intrusion Detection System monitors network or system activities and alerts administrators when suspicious activities occur.

### IDS Action

```
Detect → Alert
```

IDS does NOT stop attacks.

---

## Types of IDS

### 1. Network IDS (NIDS)

Monitors network traffic.

Location:

```
Internet
   |
 Switch
   |
  IDS
```

Examples:

* Snort
* Suricata

---

### 2. Host IDS (HIDS)

Installed on individual hosts.

Monitors:

* Log Files
* System Calls
* Registry Changes
* File Integrity

Examples:

* OSSEC

---

## IDS Detection Methods

### Signature-Based Detection

Matches known attack patterns.

Advantages:

* Accurate

Disadvantages:

* Cannot detect unknown attacks

---

### Anomaly-Based Detection

Detects deviations from normal behavior.

Advantages:

* Detects unknown attacks

Disadvantages:

* False Positives

---

### Hybrid Detection

Combination of both methods.

---

## IDS Advantages

* Early threat detection
* Security monitoring
* Incident investigation
* Compliance support

---

## IDS Disadvantages

* False positives
* Requires tuning
* Cannot block attacks

---

# 5. IPS (Intrusion Prevention System)

## What is IPS?

An Intrusion Prevention System not only detects attacks but also blocks them automatically.

### IPS Action

```
Detect → Block
```

---

## IPS Placement

```
Internet
   |
 IPS
   |
Internal Network
```

Traffic passes through IPS.

---

## Types of IPS

### 1. Network IPS (NIPS)

Protects entire network.

---

### 2. Host IPS (HIPS)

Protects individual systems.

---

### 3. Wireless IPS (WIPS)

Protects wireless networks.

Detects:

* Rogue Access Points
* Wireless Attacks

---

## IPS Techniques

### Signature-Based

Uses known attack signatures.

---

### Anomaly-Based

Detects unusual traffic.

---

### Policy-Based

Uses predefined security policies.

---

## IPS Actions

* Drop Packets
* Reset Connections
* Block IP Addresses
* Alert Administrators
* Quarantine Traffic

---

# IDS vs IPS

| Feature      | IDS         | IPS      |
| ------------ | ----------- | -------- |
| Detection    | Yes         | Yes      |
| Prevention   | No          | Yes      |
| Placement    | Out-of-band | Inline   |
| Traffic Flow | Monitors    | Controls |
| Alerts       | Yes         | Yes      |
| Blocking     | No          | Yes      |

---

# 6. VPN (Virtual Private Network)

## What is VPN?

A VPN creates a secure encrypted tunnel over a public network such as the Internet.

Purpose:

* Secure Communication
* Remote Access
* Data Privacy

---

## Why VPN is Needed

Without VPN:

```
User ---- Internet ---- Server
```

Data can be intercepted.

With VPN:

```
User ==Encrypted Tunnel== Server
```

Data remains secure.

---

## VPN Benefits

* Encryption
* Privacy
* Secure Remote Access
* Data Protection
* Bypass Geographic Restrictions

---

## VPN Components

### VPN Client

User device initiating connection.

### VPN Server

Accepts VPN connections.

### Encryption Protocol

Protects transmitted data.

---

## Types of VPN

### 1. Remote Access VPN

Used by individual users.

Example:
Employee working from home.

```
Employee
    |
 VPN
    |
Company Network
```

---

### 2. Site-to-Site VPN

Connects two networks.

Example:
Branch Office ↔ Headquarters

```
Office A ===== VPN ===== Office B
```

---

## VPN Protocols

### PPTP (Point-to-Point Tunneling Protocol)

Advantages:

* Easy setup

Disadvantages:

* Weak security

---

### L2TP/IPSec

Combines:

* L2TP
* IPSec Encryption

Advantages:

* Stronger security

---

### IPSec

Industry standard VPN protocol.

Provides:

* Authentication
* Encryption
* Integrity

Modes:

#### Transport Mode

Encrypts only payload.

#### Tunnel Mode

Encrypts entire packet.

---

### SSL/TLS VPN

Uses web browsers.

Examples:

* Corporate VPN Portals

---

### OpenVPN

Open-source VPN solution.

Advantages:

* Strong security
* Cross-platform

---

### WireGuard

Modern VPN protocol.

Advantages:

* Fast
* Lightweight
* Secure

---

## VPN Security Features

### Encryption

Algorithms:

* AES-128
* AES-256

---

### Authentication

Methods:

* Username/Password
* Certificates
* Multi-Factor Authentication (MFA)

---

### Integrity Checking

Ensures data is not modified.

Techniques:

* SHA Hashing
* HMAC

---

# Firewall vs IDS vs IPS vs VPN

| Feature         | Firewall | IDS | IPS | VPN     |
| --------------- | -------- | --- | --- | ------- |
| Filters Traffic | Yes      | No  | Yes | No      |
| Detects Attacks | Limited  | Yes | Yes | No      |
| Blocks Attacks  | Yes      | No  | Yes | No      |
| Encryption      | No       | No  | No  | Yes     |
| Remote Access   | No       | No  | No  | Yes     |
| Monitoring      | Yes      | Yes | Yes | Limited |
