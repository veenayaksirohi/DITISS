# Firewall

## What is a Firewall?

A **Firewall** is a security device/software that monitors, filters, and controls incoming and outgoing network traffic based on predefined security rules.

### Functions

* Prevent unauthorized access
* Allow legitimate traffic
* Monitor network activity
* Protect against attacks
* Enforce security policies

---

# Firewall Architecture

## 1-Tier Architecture

### Definition

A single firewall protects the entire network.

### Architecture

```text
Internet
    |
 Firewall
    |
Internal Network
```

### Advantages

* Simple setup
* Low cost
* Easy management

### Disadvantages

* Single point of failure
* Lower security

### Use Case

* Small organizations
* Home networks

---

## 2-Tier Architecture

### Definition

Uses two firewalls to create a secure zone called a DMZ (Demilitarized Zone).

### Architecture

```text
Internet
    |
External Firewall
    |
    DMZ
(Web/Mail Server)
    |
Internal Firewall
    |
Internal Network
```

### Advantages

* Better security
* Separation of public and private servers

### Disadvantages

* Higher cost
* More complex management

### Use Case

* Medium-sized organizations
* Companies hosting web servers

---

## N-Tier Architecture

### Definition

Uses multiple security layers and firewalls.

### Architecture

```text
Internet
    |
Firewall 1
    |
DMZ
    |
Firewall 2
    |
Application Layer
    |
Firewall 3
    |
Database Layer
```

### Advantages

* Very high security
* Layered defense (Defense in Depth)

### Disadvantages

* Expensive
* Complex administration

### Use Case

* Banks
* Government organizations
* Data centers

---

# Firewall Types Based on Implementation

## Hardware Firewall

### Definition

A dedicated physical device placed between networks.

### Examples

* Cisco Firepower
* Fortinet FortiGate
* Palo Alto Networks NGFW

### Architecture

```text
Internet
    |
Hardware Firewall
    |
LAN
```

### Advantages

* High performance
* Protects entire network
* Difficult to bypass

### Disadvantages

* Expensive
* Requires dedicated hardware

---

## Software Firewall

### Definition

Firewall software installed on a host machine.

### Examples

* Windows Defender Firewall
* iptables
* UFW

### Architecture

```text
Computer
    |
Software Firewall
    |
Applications
```

### Advantages

* Low cost
* Easy installation
* Host-level protection

### Disadvantages

* Uses system resources
* Protects only the installed host

---

# Hardware Firewall vs Software Firewall

| Feature     | Hardware Firewall | Software Firewall          |
| ----------- | ----------------- | -------------------------- |
| Location    | Network Edge      | Individual Host            |
| Cost        | High              | Low                        |
| Performance | High              | Moderate                   |
| Protection  | Entire Network    | Single Device              |
| Maintenance | Specialized       | Easy                       |
| Examples    | FortiGate, Cisco  | Windows Firewall, iptables |

# Firewalls Based on Filtering Techniques

## A) Packet Filtering Firewall

### Definition

Examines packet headers and makes decisions based on predefined rules.

### Checks

* Source IP Address
* Destination IP Address
* Source Port
* Destination Port
* Protocol (TCP/UDP/ICMP)

### Working

```text
Packet Arrives
      |
Check Rule Table
      |
Allow / Deny
```

### Example Rule

```bash
iptables -A INPUT -p tcp --dport 22 -j ACCEPT
```

Allows SSH traffic on Port 22.

### Advantages

* Fast
* Low overhead
* Easy implementation

### Disadvantages

* Cannot inspect packet content
* Vulnerable to spoofing attacks

### OSI Layer

**Layer 3 (Network)** and **Layer 4 (Transport)**

---

## B) Application Proxy Firewall (Application-Level Gateway)

### Definition

Acts as an intermediary between client and server and inspects application data.

### Architecture

```text
Client
   |
Proxy Firewall
   |
Web Server
```

### Working

1. Client sends request to proxy.
2. Proxy analyzes request.
3. If allowed, proxy forwards request to server.
4. Server response returns through proxy.

### Example

```text
User --> Proxy --> Website
```

### Protocols Supported

* HTTP
* HTTPS
* FTP
* SMTP
* DNS

### Advantages

* Deep packet inspection
* Hides internal network
* Strong security

### Disadvantages

* Slower than packet filtering
* More resource consumption

### OSI Layer

**Layer 7 (Application Layer)**

# Exam Summary (2 Marks)

**Firewall:** Security system that monitors and controls network traffic based on security rules.

**1-Tier:** Single firewall protecting network.

**2-Tier:** Two firewalls with DMZ between them.

**N-Tier:** Multiple firewalls providing layered security.

**Hardware Firewall:** Dedicated physical firewall device.

**Software Firewall:** Firewall software installed on a host.

**Packet Filtering Firewall:** Filters packets using IP, port, and protocol information.

**Application Proxy Firewall:** Intercepts and inspects application-level traffic before forwarding it.
