# Cryptography Algorithms Explained

## 1. Substitution Cipher

### Definition

In a substitution cipher, each letter of the plaintext is replaced by another letter, symbol, or number.

---

# A. Caesar Cipher

### Definition

Each letter is shifted by a fixed number of positions in the alphabet.

### Formula

[
C = (P + K) \mod 26
]

Where:

* C = Ciphertext letter
* P = Plaintext letter
* K = Shift key

### Example (Key = 3)

Plaintext:

```text
HELLO
```

Encryption:

```text
H → K
E → H
L → O
L → O
O → R
```

Ciphertext:

```text
KHOOR
```

### Advantages

* Very simple
* Fast

### Disadvantages

* Easy to break using brute force (only 25 keys)

---

# B. Monoalphabetic Cipher

### Definition

Each plaintext letter is mapped to a unique ciphertext letter.

### Example Mapping

```text
Plain : ABCDEFGHIJKLMNOPQRSTUVWXYZ
Cipher: QWERTYUIOPASDFGHJKLZXCVBNM
```

Plaintext:

```text
HELLO
```

Encryption:

```text
H → I
E → T
L → S
L → S
O → G
```

Ciphertext:

```text
ITSSG
```

### Advantages

* More secure than Caesar

### Disadvantages

* Vulnerable to frequency analysis

---

# C. Vigenère Cipher

### Definition

Uses multiple Caesar ciphers based on a keyword.

### Example

Plaintext:

```text
ATTACKATDAWN
```

Key:

```text
LEMONLEMONLE
```

Encryption Table:

| Plain  | A | T | T | A | C | K |
| ------ | - | - | - | - | - | - |
| Key    | L | E | M | O | N | L |
| Cipher | L | X | F | O | P | V |

Ciphertext:

```text
LXFOPVEFRNHR
```

### Advantages

* Stronger than Monoalphabetic Cipher

### Disadvantages

* Can be broken using statistical attacks

---

# D. Playfair Cipher

### Definition

Encrypts pairs of letters (digraphs) instead of single letters.

### Step 1: Create 5×5 Matrix

Keyword:

```text
MONARCHY
```

Matrix:

```text
M O N A R
C H Y B D
E F G I K
L P Q S T
U V W X Z
```

(I and J are treated as same)

### Example

Plaintext:

```text
HELLO
```

Pairs:

```text
HE LL OX
```

Encryption Rules

1. Same Row → Move right
2. Same Column → Move down
3. Rectangle → Take opposite corners

Ciphertext:

```text
CF PP NV
```

### Advantages

* Hides letter frequency

### Disadvantages

* Complex compared to Caesar

---

# E. Hill Cipher

### Definition

Uses matrix multiplication for encryption.

### Key Matrix

```text
|3 3|
|2 5|
```

### Plaintext

```text
HI
```

Convert letters:

```text
H = 7
I = 8
```

Vector:

```text
|7|
|8|
```

Encryption:

```text
|3 3| × |7|
|2 5|   |8|
```

Result:

```text
|45|
|54|
```

Mod 26:

```text
19 → T
2  → C
```

Ciphertext:

```text
TC
```

### Advantages

* Strong mathematical security

### Disadvantages

* Matrix inverse required for decryption

---

# 2. Transposition Cipher

### Definition

Characters are not replaced; only their positions are rearranged.

---

# F. Rail Fence Cipher

### Definition

Characters are written in a zig-zag pattern across rows.

### Example

Plaintext:

```text
HELLOWORLD
```

Rails = 3

Arrangement:

```text
H   O   L
 E L W R D
  L   O
```

Read row-wise:

```text
HOL ELWRD LO
```

Ciphertext:

```text
HOLELWRDLO
```

### Advantages

* Easy implementation

### Disadvantages

* Weak security

---

# G. Columnar Transposition Cipher

### Definition

Write plaintext in rows and read columns according to a key.

### Example

Key:

```text
ZEBRA
```

Plaintext:

```text
ATTACKATDAWN
```

Table:

```text
Z E B R A
---------
A T T A C
K A T D A
W N X X X
```

Number columns alphabetically:

```text
A B E R Z
5 2 3 4 1
```

Read columns:

```text
CAX TTX TAN ADX AKW
```

Ciphertext:

```text
CAXTTXTANADXAKW
```

### Advantages

* Better than Rail Fence

### Disadvantages

* Frequency patterns still exist

---

# H. Double Transposition Cipher

### Definition

Apply Columnar Transposition twice using two different keys.

### Process

```text
Plaintext
    ↓
1st Columnar Transposition
    ↓
Intermediate Ciphertext
    ↓
2nd Columnar Transposition
    ↓
Final Ciphertext
```

### Example

```text
Plaintext:
ATTACKATDAWN

Key1:
ZEBRA

Key2:
HOUSE
```

After first transposition:

```text
CAXTTXTANADXAKW
```

After second transposition:

```text
Further scrambled ciphertext
```

### Advantages

* Much stronger than single transposition
* Used in military communications

### Disadvantages

* More complex encryption/decryption

# Quick Comparison Table

| Algorithm            | Type          | Key Used        | Encrypts          |
| -------------------- | ------------- | --------------- | ----------------- |
| Caesar               | Substitution  | Shift value     | Single letters    |
| Monoalphabetic       | Substitution  | Mapping table   | Single letters    |
| Vigenère             | Substitution  | Keyword         | Single letters    |
| Playfair             | Substitution  | 5×5 Matrix      | Letter pairs      |
| Hill                 | Substitution  | Matrix          | Blocks of letters |
| Rail Fence           | Transposition | Number of rails | Rearrangement     |
| Columnar             | Transposition | Keyword         | Rearrangement     |
| Double Transposition | Transposition | Two keywords    | Rearrangement     |

### Exam Shortcut

**Substitution**

* Caesar → Fixed Shift
* Monoalphabetic → One Mapping
* Vigenère → Multiple Shifts
* Playfair → Letter Pairs
* Hill → Matrix Math

**Transposition**

* Rail Fence → Zig-Zag
* Columnar → Row-Column Rearrangement
* Double Transposition → Columnar Twice
