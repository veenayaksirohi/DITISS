# Practical: GeoIP Based IP Filtering using iptables and xtables-addons

## Objective

To block or allow network traffic based on the **country (geographical location)** from which the packet originates.

Instead of blocking one IP address at a time, we block an entire country's IP ranges using the GeoIP database.

Example:

* Block all traffic from China
* Allow only India and the USA
* Log all packets coming from Russia

---

# Theory

## What is GeoIP?

GeoIP is a database that maps

```
IP Address  ---> Country
```

Example

```
8.8.8.8       -> United States
180.x.x.x     -> China
49.x.x.x      -> India
```

Using this database, Linux can determine the country of an incoming IP address.

---

## What is iptables?

iptables is the Linux firewall.

It creates firewall rules such as

```
Accept packet
Drop packet
Reject packet
Log packet
```

---

## What is xtables-addons?

iptables itself **cannot identify countries**.

The **xtables-addons** package adds extra matching modules to iptables.

One of these modules is

```
geoip
```

which allows rules like

```
Drop packets coming from China
```

---

## What is xt_geoip?

xt_geoip is an extension provided by xtables-addons.

It contains two important utilities.

### xt_geoip_dl

Downloads the GeoIP database.

### xt_geoip_build

Converts the downloaded CSV database into the binary format required by iptables.


Each file contains binary IP ranges belonging to that country.

# Step 13 Block China

```bash
sudo iptables -I INPUT -m geoip --src-cc CN -j DROP
```

---

# Parameter Explanation

## -I

Insert rule

By default

```
Rule becomes Rule Number 1
```

so it is checked first.

---

## INPUT

Incoming packets.

Rule applies only to traffic entering this machine.

---

## -m geoip

Use GeoIP matching module.

Without this

```
--src-cc
```

will not work.

---

## --src-cc

Source Country Code

Looks at sender IP

Example

```
CN
```

means

If source IP belongs to China.

Other examples

```
IN

India

US

United States

JP

Japan

RU

Russia
```

---

## -j

Jump

Specifies what action should happen after the packet matches.

---

## DROP

Silently discard packet.

Sender never receives a reply.

---

# Packet Flow

```text
Incoming Packet

↓

Source IP

↓

GeoIP Lookup

↓

Country = CN ?

↓

Yes

↓

DROP

↓

Packet discarded
```

```
alert

err
warning
notice
info
debug
```

---

```
| Traffic from China |
```

```
PROTO=TCP
```

# Common iptables Targets

| Target | Meaning                  |
| ------ | ------------------------ |
| ACCEPT | Allow packet             |
| DROP   | Silently discard packet  |
| REJECT | Reject and notify sender |
| LOG    | Log packet only          |
| RETURN | Return to previous chain |

---

# Common iptables Chains

| Chain   | Purpose                                      |
| ------- | -------------------------------------------- |
| INPUT   | Incoming packets                             |
| OUTPUT  | Outgoing packets                             |
| FORWARD | Packets passing through the machine (router) |
