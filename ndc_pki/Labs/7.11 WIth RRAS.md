# Step 1 - Remove Existing IP Address (Windows)

Open Command Prompt as Administrator.

Display current configuration:

```cmd
ipconfig
```

Remove any old IP address (if required):

```cmd
netsh interface ip delete address "Ethernet"
```

or

```cmd
netsh interface ipv4 reset
```

---

# Step 2 - Remove Existing Routes

Display routes:

```cmd
route print
```

Delete old default route:

```cmd
route delete 0.0.0.0
```

Delete any unwanted route:

```cmd
route delete <network>
```

Example

```cmd
route delete 192.168.40.0
```

---

# Step 3 - Assign Static IP Addresses

Assign the IPs mentioned above to each machine.

Verify using:

```cmd

```

or

```bash

```

on Linux.

# Why Machine A Can Reach Machine C

Machine A sends packets destined for another network to its default gateway.

```
Gateway = 192.168.40.10
```

Windows Server (RRAS)

↓

Receives packet

↓

Looks at routing table

↓

Forwards packet to

```
192.168.50.0/24
```

↓

Machine C receives packet

↓

Replies back through

```
192.168.50.10
```

↓

RRAS forwards it back to Machine A.

# Important Notes

- All machines must have **Static IP addresses**.
- Machine A's default gateway must be **192.168.40.10**.
- Machine C's default gateway must be **192.168.50.10**.
- Windows Server (Machine B) **should not have a default gateway configured** on either NIC in this lab.
- RRAS must be configured with **Custom Configuration → LAN Routing**.
- VPN is **not required** for this scenario.
- After starting RRAS, routing between both networks is automatic.

### Corrections from your original notes

1. **RRAS Configuration:** Use **Custom Configuration → LAN Routing**, **not** "Custom VPN".
2. **RRAS Installation:** Install **Remote Access → Routing** only. VPN is unnecessary.
3. **CMAK:** **Connection Manager Administration Kit (CMAK)** is **not required** for this routing lab. It's used to create VPN connection packages for clients.
4. **IIS:** RRAS is **not part of IIS**. It is a separate Windows Server role under **Remote Access**.
5. **Default Gateway on Server:** Leave the **gateway blank** on both server adapters in this two-network routing lab. Only the client machines (A and C) need a default gateway pointing to the server.
