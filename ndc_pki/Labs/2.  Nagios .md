# Nagios Core Installation Lab (Debian VM)

This guide contains the complete procedure with missing steps added, corrections, and explanations.

---

# Lab Prerequisites

* OS: Debian 12 (Recommended)
* Internet Connection
* Root or sudo privileges
* VM Memory: Minimum 2 GB RAM
* Apache2 will be used as the web server.

---

# Step 1: Configure Server

## 1. Change Hostname

```bash
sudo hostnamectl set-hostname luffy
```

Edit hosts file:

```bash
sudo nano /etc/hosts
```

Change

```text
127.0.1.1    debian
```

to

```text
127.0.1.1    luffy
```

Verify

```bash
hostname
hostnamectl
```

---

## 2. Set Time Zone

Show available timezones

```bash
timedatectl list-timezones
```

Set Indian timezone

```bash
sudo timedatectl set-timezone Asia/Kolkata
```

Verify

```bash
timedatectl
```

---

# Step 3: Configure Static IP

Check interface

```bash
ip a
```

Usually

```
ens33
```

or

```
eth0
```

Edit network configuration

```bash
sudo nano /etc/network/interfaces
```

Example

```text
auto ens33

iface ens33 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 1.1.1.1
```

Restart networking

```bash
sudo systemctl restart networking
```

or

```bash
sudo ifdown ens33
sudo ifup ens33
```

Verify

```bash
ip a
ip route
ping google.com
```

Automatic

```bash

```

If not created

```bash

```

```bash

```

(Optional)

```bash

```

Verify

```bash

```

Check Apache process

```bash

```

Example

```bash

```

```

```

```bash

```

Verify


# Common Troubleshooting

| Problem              | Solution                                                                           |
| -------------------- | ---------------------------------------------------------------------------------- |
| `./configure` fails  | Install missing dependency and rerun `./configure`                                 |
| `make` fails         | Read the last error message; it usually indicates a missing library or compiler    |
| HTTP 403/404         | Ensure `install-webconf` was run and Apache modules (`rewrite`, `cgi`) are enabled |
| Cannot log in        | Recreate the `nagiosadmin` user with `htpasswd`                                    |
| Configuration errors | Run `nagios -v /usr/local/nagios/etc/nagios.cfg` and fix the reported line         |
| Plugins not found    | Verify `/usr/local/nagios/libexec` exists and plugins were installed               |
| Service won't start  | Check `journalctl -u nagios` and `/usr/local/nagios/var/nagios.log` for details    |
