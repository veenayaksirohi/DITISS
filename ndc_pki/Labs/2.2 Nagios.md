# Nagios NCPA Monitoring for Debian Linux

> **Scenario:** Nagios Core is already installed and working. NCPA monitoring for Windows is already configured. Now you want to monitor a **Debian Linux machine** using the **NCPA Agent**.

---

## Lab Setup

| Machine        | Purpose               | IP Address          |
| -------------- | --------------------- | ------------------- |
| Nagios Server  | Nagios Core + Plugins | **192.168.129.128** |
| Debian Machine | Machine to Monitor    | **192.168.129.130** |

> **Note:** If your IP addresses change, replace them everywhere in the configuration files and commands.

---

# Step 1: Install NCPA Agent on Debian Machine

Move to the Debian machine that you want to monitor.

### Install required dependency

```bash
sudo apt update
sudo apt install libsqlite3-0 -y
```

---

## Download NCPA

Download the latest Linux NCPA package from the Nagios website.

Example:

```bash
wget https://assets.nagios.com/downloads/ncpa/ncpa-latest.amd64.deb
```

Or copy it from another server.

---

## Install NCPA

```bash
sudo dpkg -i ncpa-latest.amd64.deb
```

If dependency errors occur:

```bash
sudo apt --fix-broken install
```

---

# Step 2: Configure NCPA

Open the configuration file.

```bash
sudo vi /usr/local/ncpa/etc/ncpa.cfg
```

Find:

```ini
community_string = mytoken
```

Change it to your own token if required.

Example

```ini
community_string = password1234
```

Save and exit.

---

# Step 3: Start NCPA Service

Restart the service.

```bash
sudo systemctl restart ncpa_listener
sudo systemctl restart ncpa_passive
```

or

```bash
sudo systemctl restart ncpa
```

(Depends on NCPA version.)

Check status:

```bash
sudo systemctl status ncpa_listener
```

or

```bash
sudo systemctl status ncpa
```

Enable service at boot:

```bash
sudo systemctl enable ncpa_listener
```

---

# Step 4: Verify NCPA Web Interface

From a browser, open

```
https://192.168.129.130:5693
```

You should see the NCPA login page.

Use your configured token when prompted.

If the page does not open, check:

```bash
sudo ss -tulpn | grep 5693
```

Allow the firewall if enabled:

```bash
sudo ufw allow 5693/tcp
```

---

# Step 5: Test NCPA from Nagios Server

Go to Nagios Server.

```bash
cd /usr/local/nagios/libexec
```

Run a test.

```bash
sudo ./check_ncpa.py -H 192.168.129.130 \
-t mytoken \
-M "disk/logical/|" \
-w 70 -c 90

```

If everything is correct, you should receive an **OK** response.

---

# Step 6: Add Debian Host

Go to

```bash
cd /usr/local/nagios/etc/servers
```

Create or edit:

```bash
deb_12-1.cfg
```

Add:

```cfg
define host{

    use                     linux-server
    host_name               deb_12-1
    alias                   Debian 12 System
    address                 192.168.129.130

    max_check_attempts      3
    check_period            24x7
    notification_interval   30
    notification_period     24x7
}
```

---

# Step 7: Add NCPA Services

## Check Agent Version

```cfg
define service{

    use                     generic-service
    host_name               deb_12-1
    service_description     NCPA Agent Version

    check_command           check_ncpa!-t 'mytoken' -P 5693 -M system/agent_version
}
```

---

## Check CPU Usage

```cfg
define service{

    use                     generic-service
    host_name               deb_12-1
    service_description     CPU Usage

    check_command           check_ncpa!-t 'mytoken' -P 5693 -M cpu/percent -w 80 -c 90
}
```

---

## Check Memory Usage

```cfg
define service{

    use                     generic-service
    host_name               deb_12-1
    service_description     Memory Usage

    check_command           check_ncpa!-t 'mytoken' -P 5693 -M memory/virtual -w 80 -c 90 -u G -q aggregate=avg
}
```

---

## Check Disk Usage

```cfg
define service{

    use                     generic-service
    host_name               deb_12-1
    service_description     Root Disk

    check_command           check_ncpa!-t 'mytoken' -P 5693 -M disk/logical/ -w 80 -c 90 -u G
}
```

---

## Check Load Average

```cfg
define service{

    use                     generic-service
    host_name               deb_12-1
    service_description     Load Average

    check_command           check_ncpa!-t 'mytoken' -P 5693 -M cpu/load/1
}
```

---

# Step 8: Validate Nagios Configuration

```bash
/usr/local/nagios/bin/nagios -v /usr/local/nagios/etc/nagios.cfg
```

Expected output:

```
Total Warnings: 0

Total Errors: 0

Things look okay.
```

# Step 9: Restart Nagios

```bash
sudo systemctl restart nagios
```

Check status:

```bash
sudo systemctl status nagios
```

# Step 10: Open Nagios Web Interface

Open:

```
http://192.168.129.128/nagios
```

Navigate to

```
Hosts
```

You should see

```
deb_12-1
```

Click on the host to view all configured services.

# Common NCPA Modules

| Module                 | Purpose               |
| ---------------------- | --------------------- |
| `system/agent_version` | NCPA Version          |
| `cpu/percent`          | CPU Utilization       |
| `cpu/load/1`           | 1-Minute Load Average |
| `memory/virtual`       | Virtual Memory Usage  |
| `memory/physical`      | Physical RAM Usage    |
| `disk/logical/`        | Disk Usage            |
| `disk/logical/root`    | Root Filesystem       |
| `processes`            | Running Processes     |
| `interface`            | Network Interfaces    |
| `system/uptime`        | System Uptime         |
| `services`             | Running Services      |

---

# Useful Commands

```bash
# Restart NCPA
sudo systemctl restart ncpa

# Check NCPA Status
sudo systemctl status ncpa

# Validate Nagios
/usr/local/nagios/bin/nagios -v /usr/local/nagios/etc/nagios.cfg

# Restart Nagios
sudo systemctl restart nagios

# Check Plugin
cd /usr/local/nagios/libexec

sudo ./check_ncpa.py -H 192.168.129.130 -t mytoken -M system/agent_version

# Check CPU
sudo ./check_ncpa.py -H 192.168.129.130 -t mytoken -M cpu/percent

# Check Memory
sudo ./check_ncpa.py -H 192.168.129.130 -t mytoken -M memory/virtual

# Check Disk
sudo ./check_ncpa.py -H 192.168.129.130 -t mytoken -M disk/logical/
```

## Notes

* Replace all IP addresses if your lab network changes.
* Ensure the **community_string (token)** in `ncpa.cfg` matches the token used in every `check_ncpa` command.
* Verify that TCP port **5693** is reachable from the Nagios server.
* Always run `nagios -v` before restarting Nagios to catch configuration errors.
* Since Windows NCPA is already working in your setup, the plugin configuration (`check_ncpa`) on the Nagios server should already exist. For the Debian host, you mainly need to install the NCPA agent, configure the token, add the host and services, validate the configuration, and restart Nagios.
