# Suricata IDS Practical (Ping Detection)

## Step 1: Install Suricata

```bash
sudo apt update
sudo apt install suricata -y
```

> If `Package 'suricata' has no installation candidate` appears, enable the appropriate repository or install from the official Suricata repository.

---

# Step 2: Edit Suricata Configuration

Open the configuration file.

```bash
sudo vi /etc/suricata/suricata.yaml
```

Search for:

```
/af-packet
```

Modify your network interface.

Example:

```yaml
af-packet:
  - interface: ens33
```

Replace **ens33** with your actual interface.

Check interface name:

```bash
ip a
```

---

# Step 3: Configure Rule File

Search for:

```
rule-files:
```

You may see:

```yaml
rule-files:
  #- suricata.rules
```

Comment the default rule if present and add:

```yaml
rule-files:
  - local.rules
```

Save:

```
:wq
```

---

# Step 4: Create Local Rule

Open:

```bash
sudo vi /etc/suricata/rules/local.rules
```

Add:

```text
alert icmp any any -> any any (msg:"Ping Detected"; sid:1000001; rev:1;)
```

### Explanation

* **alert** → Generate an alert
* **icmp** → ICMP protocol (Ping)
* **any any** → Source IP and Port
* **->** → Direction
* **any any** → Destination IP and Port
* **msg** → Alert message
* **sid** → Unique Rule ID (must be unique; values above 1,000,000 are commonly used for local rules)
* **rev** → Rule revision number

Save:

```
:wq
```

---

# Step 5: Verify Configuration

Always test before starting.

```bash
sudo suricata -T -c /etc/suricata/suricata.yaml
```

Expected:

```
Configuration provided was successfully loaded.
```

---

# Step 6: Start Suricata

```bash
sudo systemctl start suricata
```

Enable at boot (optional):

```bash
sudo systemctl enable suricata
```

---

# Step 7: Check Status

```bash
sudo systemctl status suricata
```

Expected:

```
Active: active (running)
```

---

# Step 8: Monitor Alerts

```bash
sudo tail -f /var/log/suricata/fast.log
```

---

# Step 9: Generate Traffic

From another machine:

```bash
ping <Suricata_IP>
```

Example:

```bash
ping 192.168.1.10
```

---

# Step 10: Verify Detection

In `fast.log` you should see something like:

```text
07/01/2026-10:15:24 [**] [1:1000001:1] Ping Detected [**]
```

## Common Mistakes

* ❌ `aptget` → ✅ `apt`
* ❌ `sudo vi etc/suricata/rules/local.rules` → ✅ `sudo vi /etc/suricata/rules/local.rules`
* ❌ `sid:123` → Use a unique SID like `1000001`
* ❌ `rev;1` → ✅ `rev:1;`
* Ensure the correct interface (`ens33`, `ens160`, `eth0`, etc.) is configured in `suricata.yaml`.
* After changing the configuration or rules, restart Suricata:

```bash
sudo systemctl restart suricata
```
