# Suricata IPS

**Suricata** is an open-source **Intrusion Detection System (IDS)**, **Intrusion Prevention System (IPS)**, and **Network Security Monitoring (NSM)** engine. It inspects network traffic using signatures and protocol analysis to detect or block malicious activity.

### NFQUEUE

**NFQUEUE** is a feature of the **Linux kernel's Netfilter framework**.

* It allows network packets to be **queued from the kernel to a user-space application**.
* A user-space program such as **Suricata** inspects each packet.
* After inspection, the application returns a **verdict** to the kernel:

  * **ACCEPT** – Allow the packet.
  * **DROP** – Block the packet.
  * **REPEAT/MODIFY** (in some implementations) – Reprocess or modify the packet.

### How Suricata Uses NFQUEUE (IPS Mode)

```
Incoming Packet
       │
       ▼
Linux Netfilter (iptables/nftables)
       │
       ▼
    NFQUEUE
       │
       ▼
    Suricata
(Packet Inspection)
       │
       ├── ACCEPT ──► Packet continues to destination
       │
       └── DROP ───► Packet is discarded
```

### Example

When an attacker sends a malicious packet:

1. The packet reaches the Linux firewall.
2. An **iptables** or **nftables** rule sends the packet to **NFQUEUE**.
3. **Suricata** receives the packet from the queue.
4. Suricata compares the packet against its detection rules.
5. If a rule with **drop** action matches:

   * Suricata returns **DROP**.
   * The Linux kernel discards the packet.
6. Otherwise:

   * Suricata returns **ACCEPT**.
   * The packet continues normally.

### Key Points

* **NFQUEUE** is a Linux kernel mechanism that passes packets to user-space applications.
* **Suricata** uses NFQUEUE to operate in **IPS (Intrusion Prevention System)** mode.
* Packet inspection occurs in **user space**, while the final forwarding or dropping is performed by the **Linux kernel** based on Suricata's verdict.
* Without NFQUEUE, Suricata typically runs in **IDS mode**, where it only monitors and alerts on traffic rather than blocking it.





# Suricata IPS using NFQUEUE (Commands + Short Notes)

---

# 1. Check Suricata Installation

Check whether Suricata is installed.

```bash
which suricata
```

If not installed:

```bash
sudo apt update
sudo apt install suricata
```

---

# 2. Verify NFQUEUE Support

Suricata must be compiled with **NFQUEUE** support to work in **IPS mode**.

```bash
suricata --build-info | grep NFQueue
```

Expected output:

```text
NFQueue support: yes
```

---

# 3. Configure Suricata

Open the configuration file:

```bash
sudo vi /etc/suricata/suricata.yaml
```

---

## Step 3.1 Configure NFQUEUE

Search:

```text
/nfq
```

Uncomment/configure:

```yaml
nfq:
  mode: accept
  repeat-mark: 1
  repeat-mask: 1
  route-queue: 2
```

### Short Notes

* **mode: accept** → Suricata accepts packets unless a rule drops them.
* **repeat-mark** → Marks packets already processed to avoid processing them again.
* **repeat-mask** → Mask used with repeat-mark.
* **route-queue: 2** → Send packets back to queue number **2** after processing.

---

## Step 3.2 Configure Network Interface

Search:

```text
/af-packet
```

Modify your interface.

Example:

```yaml
af-packet:
  - interface: ens33
```

Replace **ens33** with your actual interface.

Check interface name:

```bash
ip a
```

---

## Step 3.3 Configure Rule File

Search:

```text
rule-files:
```

You may see:

```yaml
rule-files:
  #- suricata.rules
```

Comment the default rule if present and add:

```yaml
rule-files:
  - local.rules
```

Save and exit:

```text
:wq
```

---

# 4. Create IPS Rule

Open the local rule file:

```bash
sudo vi /etc/suricata/rules/local.rules
```

Add the following rule:

```text
drop icmp any any -> any any (msg:"Ping Detected"; sid:1000001; rev:1;)
```

### Rule Explanation

| Field     | Meaning                               |
| --------- | ------------------------------------- |
| `drop`    | Drop the packet (IPS action).         |
| `icmp`    | Match ICMP packets (Ping).            |
| `any any` | Any source IP and any source port.    |
| `->`      | Direction from source to destination. |
| `any any` | Any destination IP and port.          |
| `msg`     | Message written to logs.              |
| `sid`     | Unique Signature ID.                  |
| `rev`     | Rule revision number.                 |

Save:

```text
:wq
```

---

# 5. Install iptables (If Required)

```bash
sudo apt install iptables
```

---

# 6. Send Packets to NFQUEUE

Send ICMP packets to **NFQUEUE 2**.

```bash
sudo iptables -I INPUT -p icmp -j NFQUEUE --queue-num 2
```

```bash
sudo iptables -I OUTPUT -p icmp -j NFQUEUE --queue-num 2
```

Verify the rules:

```bash
sudo iptables -L -v
```

---

## Command Explanation

```bash
sudo iptables -I INPUT -p icmp -j NFQUEUE --queue-num 2
```

| Parameter     | Meaning                                    |
| ------------- | ------------------------------------------ |
| `sudo`        | Run command as root.                       |
| `iptables`    | Linux firewall command.                    |
| `-I`          | Insert rule at the beginning of the chain. |
| `INPUT`       | Packets destined for this machine.         |
| `-p`          | Specify protocol.                          |
| `icmp`        | Match ICMP packets (Ping).                 |
| `-j`          | Jump to target/action.                     |
| `NFQUEUE`     | Send packets to a Netfilter Queue.         |
| `--queue-num` | Specify the queue number.                  |
| `2`           | Queue number listened to by Suricata.      |

---

# 7. Run Suricata in IPS Mode

Start Suricata and listen on **NFQUEUE 2**.

```bash
sudo suricata -c /etc/suricata/suricata.yaml -q 2
```

> **Note:** Use `-q 2` (with a space), **not** `-q2`.

---

# 8. Test the IPS

From another machine:

```bash
ping <Suricata-IP>
```

If the rule matches:

* ICMP packets are **dropped**.
* Ping request **fails**.
* Suricata logs the event.

```text
     NFQUEUE (Queue 2)
```

# Exam Points

* **Suricata** = Open-source **IDS + IPS + NSM** (Network Security Monitoring) engine.
* **IDS (Intrusion Detection System)** = Detects attacks and generates alerts only.
* **IPS (Intrusion Prevention System)** = Detects attacks and blocks malicious packets.
* **NFQUEUE** = Linux **Netfilter** feature that sends packets from **kernel space** to **user space**.
* **iptables** redirects selected packets to an **NFQUEUE**.
* **Suricata** receives packets from the queue, inspects them against its rules, and returns a verdict.
* Possible verdicts:

  * **ACCEPT** → Packet is allowed.
  * **DROP** → Packet is blocked.
* Without **NFQUEUE**, Suricata mainly works in **IDS mode** (detect and alert).
* With **NFQUEUE**, Suricata works in **IPS mode** (detect and block).

```
| `-j`          | Jump to the specified target/action.                                   |

| `--queue-num` | Specify the NFQUEUE number to send packets to.                         |
| `2`           | Queue number **2**; the user-space application must listen on queue 2. |
```
