# Step 5 : Tell Nagios About the Plugin

Nagios doesn't automatically know about newly copied plugins.

Open

```bash
sudo vi /usr/local/nagios/etc/objects/commands.cfg
```

Go to the bottom.

Add

```cfg
define command{
    command_name    check_ncpa
    command_line    $USER1$/check_ncpa.py -H $HOSTADDRESS$ $ARG1$
}
```

---

## Explanation

### Line 1

```cfg
command_name check_ncpa
```

This creates the command name used later inside services.

Example

```
check_command check_ncpa!...
```

---

### Line 2

```cfg
command_line $USER1$/check_ncpa.py -H $HOSTADDRESS$ $ARG1$
```

Actual command Nagios executes.

Macros

| Macro           | Meaning                                      |
| --------------- | -------------------------------------------- |
| `$USER1$`       | Plugin directory (/usr/local/nagios/libexec) |
| `$HOSTADDRESS$` | Host IP                                      |
| `$ARG1$`        | Arguments passed from service definition     |

---

# Nagios Macros

Macros are variables enclosed within `$`.

Example

```
$HOSTNAME$
$HOSTADDRESS$
$USER1$
$SERVICEDESC$
```

Types

* User Macros
* Host Macros
* Service Macros
* Contact Macros
* Date/Time Macros

# Add Service (Agent Version)

```cfg
define service{

    use                     generic-service
    host_name               win_10_1
    service_description     NCPA Agent Version

    check_command check_ncpa!-t 'password1234' -P 5693 -M system/agent_version

}
```

---

# Add CPU Service

```cfg
define service{

    use                     generic-service
    host_name               win_10_1
    service_description     CPU Average

    check_command check_ncpa!-t 'password1234' -P 5693 -M cpu/percent -w 20 -c 40 -q aggregate=avg

}
```

---

### Meaning

| Option             | Meaning            |
| ------------------ | ------------------ |
| `-P`               | Port               |
| `-M`               | Metric             |
| `-w`               | Warning Threshold  |
| `-c`               | Critical Threshold |
| `-q aggregate=avg` | Average CPU        |

# Step 12 : Ping Issue

If Host shows

```
DOWN
```

But NCPA works,

Most likely

Windows Firewall blocks ICMP.

Enable

```
Windows Defender Firewall

↓

Inbound Rules

↓

File and Printer Sharing (Echo Request - ICMPv4-In)

↓

Enable Rule
```

Or temporarily disable firewall for testing.

# Step 13 : Important Exam Question

Open

```bash
sudo vi /usr/local/nagios/etc/servers/win_10.cfg
```

Example

```cfg
define host{

    max_check_attempts      3

}
```

Nagios retries the host check **3 times** before declaring it **DOWN**.
