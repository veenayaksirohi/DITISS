# Nagios Email Alert using SWAKS + Thunderbird

## Objective

Configure Nagios to send email alerts whenever a host/service changes state (DOWN, UP, UNREACHABLE, etc.).

---

# Lab Topology

| Machine                   | IP                          | Purpose        |
| ------------------------- | --------------------------- | -------------- |
| Nagios Server (Debian 12) | **192.168.129.100**         | Nagios + SWAKS |
| Mail Server               | **192.168.0.251**           | SMTP Server    |
| Windows Base Machine      | **192.168.0.173**           | Thunderbird    |
| Host to Monitor           | Example: **192.168.80.130** | Target Host    |

# Prerequisite

Before Nagios can send email:

```
Nagios
     │

     │ SMTP
     ▼

     ▼

```

So we require

* SMTP Mail Server
* Thunderbird
* SWAKS
* Nagios

# Service Notification

# Part 7 : Add Host

Example

```
vi /usr/local/nagios/etc/objects/deb.cfg
```

```cfg
define host{

use linux-server

host_name deb12

alias Debian12

address 192.168.80.130

max_check_attempts 3

check_interval 1

notification_interval 1

notifications_enabled 1

notification_period 24x7

notification_options d,u,r,f,s

contacts nagiosadmin

}
```

Include the file in `nagios.cfg` if it is not already included.

### Corrections to your notes

* Use `resource.cfg` (singular), not `resources.cfg`.
* Remove spaces around macro assignments:

  ```cfg
  $USER6$=toor
  $USER7$=192.168.0.251
  ```

  not

  ```cfg
  $USER6$ = toor
  ```
* Use `$CONTACTEMAIL$` (singular), not `$CONTACTEMAILS`.
* Use `$USER8$`, `$USER7$`, `$USER6$`, `$USER5$` with both opening and closing `$`.
* Restart Nagios **only after** the configuration validates successfully with:

  ```
  /usr/local/nagios/bin/nagios -v /usr/local/nagios/etc/nagios.cfg
  ```
