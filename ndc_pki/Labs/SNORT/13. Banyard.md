# Snort + Barnyard2 Setup

## What is Snort?

**Snort** is an **Intrusion Detection System (IDS)** and **Intrusion Prevention System (IPS)**.

It captures network packets, analyzes them using rules, and generates alerts whenever suspicious traffic is detected.

---

## Why Barnyard2?

If Snort performs **both**:

* Packet detection
* Binary to ASCII conversion
* Database storage

then CPU load increases and Snort becomes slower.

Instead,

* Snort only detects attacks and writes logs in **Unified2 (binary)** format.
* Barnyard2 reads those binary logs.
* Converts them into readable format.
* Stores alerts into MariaDB/MySQL.

This improves Snort's efficiency.

---

# Important Configuration Files

```
/etc/snort/snort.conf
/etc/snort/barnyard2.conf
```
