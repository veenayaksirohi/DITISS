Since this is the **initial setup** for the lab, everything should be completed before starting the Root CA and Sub CA configuration.

# LAB SETUP

## Machines

| Machine   | Hostname | IP Address       | OS        |
| --------- | -------- | ---------------- | --------- |
| Machine 1 | `rootca` | `192.168.129.10` | Debian 12 |
| Machine 2 | `subca`  | `192.168.129.11` | Debian 12 |
| Machine 3 | `www`    | `192.168.129.12` | Debian 12 |

# Step 1 : Configure Static IP

On every machine edit

```bash
sudo nano /etc/network/interfaces
```

Example

### RootCA

```bash
auto ens33
iface ens33 inet static
address 192.168.129.10
netmask 255.255.255.0
gateway 192.168.129.2

dns-nameservers 192.168.129.10
dns-search shuhari.local
```

---

### SubCA

```bash
auto ens33
iface ens33 inet static
address 192.168.129.11
netmask 255.255.255.0
gateway 192.168.129.2

dns-nameservers 192.168.129.10
dns-search shuhari.local
```

---

### WWW

```bash
auto ens33
iface ens33 inet static
address 192.168.129.12
netmask 255.255.255.0
gateway 192.168.129.2

dns-search shuhari.local
```

Restart networking


# Step 5 : Configure Forward Zone

Edit

```bash
nano /etc/bind/named.conf.local
```

Add

```bash
zone "shuhari.local" {

        type master;
        file "/etc/bind/db.shuhari.local";

};

zone "129.168.192.in-addr.arpa" {

        type master;
        file "/etc/bind/db.192";

};
```

Save.

---

# Step 6 : Create Forward Zone File

Copy

```bash
cp /etc/bind/db.local /etc/bind/db.shuhari.local
```

Edit

```bash
nano /etc/bind/db.shuhari.local
```

Replace everything with

```dns
$TTL    604800
@       IN      SOA     rootca.shuhari.local. admin.shuhari.local. (

                        2
                        604800
                        86400
                        2419200
                        604800 )

@               IN      NS      rootca.shuhari.local.

rootca          IN      A       192.168.129.10
subca           IN      A       192.168.129.11
www             IN      A       192.168.129.12
```

---

# Step 7 : Create Reverse Zone

Copy

```bash
cp /etc/bind/db.127 /etc/bind/db.192
```

Edit

```bash
nano /etc/bind/db.192
```

Replace with

```dns
$TTL    604800

@       IN      SOA     rootca.shuhari.local. admin.shuhari.local. (

                        2
                        604800
                        86400
                        2419200
                        604800 )

@       IN      NS      rootca.shuhari.local.

10      IN      PTR     rootca.shuhari.local.
11      IN      PTR     subca.shuhari.local.
12      IN      PTR     www.shuhari.local.
```

# Final Lab Topology

| Hostname | FQDN                                        | IP Address     | Purpose              |
| -------- | ------------------------------------------- | -------------- | -------------------- |
| rootca   | rootca.shuhari.local                         | 192.168.129.10 | DNS Server + Root CA |
| subca    | subca.shuhari.local                          | 192.168.129.11 | Subordinate CA       |
| www      | [www.shuhari.local](http://www.shuhari.local) | 192.168.129.12 | Web Server           |

After this setup is complete and all forward/reverse DNS lookups work correctly, you're ready to proceed with creating the **Root CA**, issuing a certificate for the **Sub CA**, and finally configuring **TLS/HTTPS** on the **www** server.
