# BASE (Basic Analysis and Security Engine) Setup

## Lab Setup

| Machine   | OS                | IP Address           | Purpose              |
| --------- | ----------------- | -------------------- | -------------------- |
| Machine 1 | Debian 12         | 192.168.129.128      | MariaDB Server       |
| Machine 2 | Debian 8 (Jessie) | e.g. 192.168.129.129 | Apache + PHP5 + BASE |

---

# Step 1: Configure Debian 8 Repository

Edit the repository file.

```bash
vi /etc/apt/sources.list
```

Add

```text
deb http://archive.debian.org/debian/ jessie main
```

Save and exit.

```
:wq
```

Update packages.

```bash
apt-get update
```

Check whether update was successful.

```bash
echo $?
```

Expected output

```
0
```

---

# Step 2: Configure MariaDB (Debian 12)

By default MariaDB listens only on localhost.

Edit configuration.

```bash
vi /etc/mysql/mariadb.conf.d/50-server.cnf
```

Find

```ini
bind-address = 127.0.0.1
```

Change to

```ini
bind-address = 0.0.0.0
```

Save.

```
:wq
```

Restart MariaDB.

```bash
systemctl restart mariadb
```

Verify.

```bash
systemctl status mariadb
```

---

# Step 3: Create Database User

Login to MariaDB.

```bash
mysql -u root -p
```

Grant permissions.

```sql
GRANT CREATE, INSERT, SELECT, DELETE, UPDATE
ON snort.*
TO 'snort'@'192.168.129.%'
IDENTIFIED BY 'toor';

FLUSH PRIVILEGES;
EXIT;
```

> You can replace `192.168.129.%` with the exact Debian 8 IP if desired.

---

# Step 4: Install Required Packages (Debian 8)

Install Apache, PHP5 and required modules.

```bash
apt-get install apache2 php5 p7zip \
libapache2-mod-php5 \
php5-mcrypt \
php5-mysqlnd \
libphp-adodb \
unzip
```

During installation, note the ADOdb path.

Usually it is

```
/usr/share/php/adodb
```

You will need this during BASE installation.

---

# Step 5: Download BASE

Move to temporary directory.

```bash
cd /tmp
```

Download BASE.

```bash
wget https://sourceforge.net/projects/secureideas/files/BASE/base-1.4.5/base-1.4.5.tar.gz
```

Extract.

```bash
tar -xzf base-1.4.5.tar.gz
```

Check extracted folder.

```bash
ls -l
```

You should see

```
base-1.4.5/
```

Move it to Apache web directory.

```bash
mv base-1.4.5 /var/www/html/base
```

Give Apache ownership.

```bash
chown -R www-data:www-data /var/www/html/base
```

---

# Step 6: Configure PHP

Edit php.ini.

```bash
vi /etc/php5/apache2/php.ini
```

Search

```
/error_reporting
```

Go to the **second occurrence**.

Change

```ini
error_reporting = E_ALL
```

to

```ini
error_reporting = E_ALL & ~E_NOTICE
```

Save.

```
:wq
```

Restart Apache.

```bash
systemctl restart apache2
```

Verify.

```bash
systemctl status apache2
```

# Step 7: Open BASE

Open browser.

http://<Debian8_IP>/base

http://192.168.129.129/base

## Common Mistakes

* `aptget` → `apt-get`
* `maridb` → `mariadb`
* `mv mybase-1.4.5.tar.gz` → `mv base-1.4.5 /var/www/html/base`
* `tar -xzf tmp wget base-1.4.5.tar.gz` → `tar -xzf base-1.4.5.tar.gz`
* Ensure `bind-address = 0.0.0.0` is set on the MariaDB server.
* Verify port **3306** is reachable from the Debian 8 machine.
* The `snort` database should already exist (typically created by Snort before installing BASE).
