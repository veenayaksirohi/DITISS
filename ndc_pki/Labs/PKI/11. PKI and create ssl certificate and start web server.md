# Part 1: Configure DNS Server

## Step 1: Install Bind9 (if not installed)

```bash
sudo apt update
sudo apt install bind9 bind9-utils bind9-doc -y
sudo systemctl status bind9
```

### Meaning

* **bind9** → DNS Server software
* **bind9utils** → DNS utilities
* **bind9-doc** → Documentation

---

## Step 2: Create Forward Zone

Open

```bash
sudo nano /etc/bind/named.conf.local
```

Add

```text
zone "shurahilab.local" {
    type master;
    file "/etc/bind/db.shurahilab.local";
};
```

### Meaning

| Parameter   | Meaning                               |
| ----------- | ------------------------------------- |
| zone        | Domain name managed by DNS            |
| type master | This server is the primary DNS server |
| file        | Zone database file                    |

---

## Step 3: Create Zone File

Copy template

```bash
sudo cp /etc/bind/db.local /etc/bind/db.shurahilab.local
```

Edit

```bash
sudo nano /etc/bind/db.shurahilab.local
```

Example

```text
$TTL 604800

@   IN SOA  ns.shurahilab.local. admin.shurahilab.local. (
        1
        604800
        86400
        2419200
        604800 )

@       IN NS      ns.shurahilab.local.

ns      IN A       192.168.129.128
www     IN A       192.168.129.128
```

### Meaning

| Record | Meaning                       |
| ------ | ----------------------------- |
| SOA    | Start of Authority            |
| NS     | Name Server                   |
| A      | Maps hostname to IPv4 address |
| ns     | DNS Server hostname           |
| www    | Website hostname              |

# Certificate parameter 




When creating a **self-signed TLS certificate** using OpenSSL, you'll be asked for several parameters. These are the fields that become part of the certificate's identity (the **Distinguished Name (DN)**).

Example command:

```bash
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
-keyout server.key \
-out server.crt
```

During execution, you'll be prompted for:

| Parameter                         | Example Value            | Meaning                                                         |
| --------------------------------- | ------------------------ | --------------------------------------------------------------- |
| **Country Name (C)**              | `IN`                     | 2-letter country code (India = IN)                              |
| **State or Province Name (ST)**   | `Maharashtra`            | State where the organization is located                         |
| **Locality Name (L)**             | `Pune`                   | City or locality                                                |
| **Organization Name (O)**         | `Shurahi Lab`            | Company or organization name                                    |
| **Organizational Unit Name (OU)** | `IT Department`          | Department within the organization                              |
| **Common Name (CN)**              | `www.shurahilab.local`   | **Most important field**. Must match the website's domain name. |
| **Email Address**                 | `admin@shurahilab.local` | Administrator's email (optional)                                |

### Example Input

```text
Country Name (2 letter code) [AU]: IN
State or Province Name (full name): Maharashtra
Locality Name (eg, city): Pune
Organization Name (eg, company): Shurahi Lab
Organizational Unit Name (eg, section): IT Department
Common Name (e.g. server FQDN or YOUR name): www.shurahilab.local
Email Address: admin@shurahilab.local
```

### Important Parameters for Your Lab

| Parameter            | Value                    |
| -------------------- | ------------------------ |
| **CN (Common Name)** | `www.shurahilab.local` ✅ |
| **O (Organization)** | `Shurahi Lab`            |
| **OU (Department)**  | `IT Department`          |
| **C**                | `IN`                     |
| **ST**               | `Maharashtra`            |
| **L**                | `Pune`                   |
| **Email**            | `admin@shurahilab.local` |

### Command Options Meaning

```bash
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
-keyout server.key -out server.crt
```

| Option               | Meaning                                                     |
| -------------------- | ----------------------------------------------------------- |
| `openssl`            | Runs the OpenSSL tool                                       |
| `req`                | Creates a certificate request (or certificate with `-x509`) |
| `-x509`              | Generate a self-signed certificate instead of a CSR         |
| `-nodes`             | Do not encrypt the private key (no passphrase)              |
| `-days 365`          | Certificate validity period (365 days)                      |
| `-newkey rsa:2048`   | Generate a new 2048-bit RSA key                             |
| `-keyout server.key` | Save the private key to `server.key`                        |
| `-out server.crt`    | Save the certificate to `server.crt`                        |

### Most Important Exam Question

If the examiner asks **"Which parameter must match the website name?"**

**Answer:**

> **Common Name (CN)** must be the same as the DNS name of the website.
>
> Example:
>
> * DNS Name: `www.shurahilab.local`
> * Certificate **Common Name (CN):** `www.shurahilab.local` ✅
