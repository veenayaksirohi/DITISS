# Kibana Setup

## Install Kibana

```bash id="wvb9hs"
sudo dpkg -i kibana-8.16.1-amd64.deb
```

If dependencies are missing:

```bash id="g1nqgd"
sudo apt --fix-broken install
```

---

# Configure Kibana

Open the configuration file.

```bash id="bnkz4p"
sudo vi /etc/kibana/kibana.yml
```

Uncomment and modify:

```yaml id="e4w0z9"
server.host: "0.0.0.0"

server.port: 5601
```

Save and exit.

---

# Parameter Meaning

### server.host

Specifies the IP address on which Kibana listens.

```yaml id="v1tuj8"
server.host: "0.0.0.0"
```

`0.0.0.0` means Kibana accepts connections from any network interface.

---

### server.port

The port used by Kibana.

```yaml id="ln80za"
5601
```

Default port: **5601**

---

# Start Kibana Service

Reload systemd (optional if package was just installed).

```bash id="j2wtjlwm"
sudo systemctl daemon-reload
```

Start Kibana.

```bash id="j5e0mu"
sudo systemctl start kibana
```

Enable automatic startup.

```bash id="eycg3y"
sudo systemctl enable kibana
```

Check service status.

```bash id="stydic"
sudo systemctl status kibana
```

Expected output:

```text id="vafmqk"
active (running)
```


or

```text id="v0sl9v"
http://<server-ip>:5601
```

# Create a Data View (Index Pattern)

From the Kibana home page:

```text id="joh1vt"
☰ Menu
    ↓
Stack Management
    ↓
Data Views
    ↓
Create Data View
```

Fill in:

```text id="2nm9n0"
Name:
My APT Tracker
```

```text id="3wlcg0"
Index Pattern:
apt*
```

Click

```text id="emod99"
Save Data View
```

> **Note:** Older Kibana versions call this an **Index Pattern**. In Kibana 8.x it is called a **Data View**.

# View Logs

Go to

```text id="g01z2r"
Discover
```

Select:

```text id="0mllgb"
My APT Tracker
```

Set the time filter to:

```text id="bspkk4"
Last 1 Hour
```

You should see the APT installation logs sent by Logstash.

---

# Generate New Logs

Install a package on the Linux machine.

Example:

```bash id="cqsg6v"
sudo apt install cmatrix
```

or

```bash id="yz2hgn"
sudo apt install sl
```

Logstash reads the new log entry and stores it in Elasticsearch.

Refresh the Discover page to see the new document.

---

# View Documents

Navigate to

```text id="w7e2nh"
Discover
```

Each document represents one log event.

Example fields:

```text id="otbh88"
message

installation_status

@timestamp

host

path
```
